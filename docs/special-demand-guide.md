## 1. 특수수요가 무엇인가 — 산식이 못 세는 손님

교과서식(실험실) 산식은 손님 수를 **주민등록 인구(1km) + 유동인구(500m)** 에서 만든다. 특수수요는 이 둘에 **안 잡히는 사람**이 오는 자리를 뜻한다.

| 유형 | 안 잡히는 이유 | 산식이 하는 일 |
|---|---|---|
| 군부대 | 병사는 주민등록이 고향에 있고, 부대 안은 유동인구 집계 밖 | 주거 수요 ×2.0 |
| 대학가 | 원룸촌 학생은 주민등록이 고향에 있음 | 주거 수요 ×1.3 |
| 산업단지 | 기숙사·원룸 근로자가 주민등록 밖, 산단 안은 유동 집계 밖 | 주거 수요 ×1.4 |
| 관광유흥 | 유흥가에 밤에 모이는 사람이 유동 집계(주간 중심)에 덜 잡힘 | 주거 수요 ×1.4 |
| 기타 | 위 넷이 아닌 사유(혁신도시 통근 등) | 배수 없음 |

배수 값은 사람이 정한 게 아니라 **그 유형 매장의 실측 ÷ 배수 없는 예측**(함의 배수)에서 왔다. 군부대 금촌역 2.0·문산 2.5 → 2.0 / 산업단지 정왕 1.45·광주첨단 1.69 → 1.4 /
관광유흥 수원인계 1.40·야당 1.43 → 1.4 / 대학가 전대후문 1.70·청주대 1.74·울산대 1.47·부경대 1.04 → 1.3.

**⚠️ 두 번 세지 않는다.** 번화가에 놀러 오는 대학생·산단 근로자는 이미 유동인구 안에 있다. 창원상남(유동 17만)에 관광유흥 위에 대학가·산업단지를 얹으면 같은 사람을 두 번 센다.
2026-09-24에 재서 확인했다(합 배수는 실무 감각에는 가까워지지만 근거가 없고 신중동 같은 곳이 같이 뜬다). **유형은 하나만 고른다.**

## 2. 강도 — "높음"에만 배수가 탄다 (2026-09-24 채택, 실험실)

강도는 **그 손님이 이 매장의 주 손님층인가**다. 실험실은 넷 다 **높음일 때만** 배수를 곱한다. 보통·낮음은 배수 없음(=유형 없음과 같은 숫자).

왜 이렇게 하나 — 강도를 안 보면 틀린다:
- 오송이 "대학가/보통"으로 ×1.3을 타서 예상매출이 +8.7%p 올라 있었다(약대·행정타운은 학부 대학가가 아님 → 기타로 정정).
- 전대상대 "대학가/높음"은 2026-09-02 백테스트 보정이 올린 값이었다(보통으로 되돌림).
- 탕정역 "산업단지/보통"은 배수 없이 오차 −0.1로 맞는다. 켜면 +20.9.
- 증평 "군부대"는 사실이지만 함의 1.02 — 높음(×2)이면 +17.0으로 터진다.

**틀렸을 때 비용이 비대칭이다.** 보통인데 실제 높음이면 과소예측(문산 초기 −20 같은 모양)으로 끝나지만, 높음인데 실제 보통이면 배수가 얹혀 크게 과대(증평 +17, 탕정역 +21).
→ **모르면 보통.** 높음은 아래 체크가 다 맞을 때만.

## 3. 유형별 사전 판정 체크리스트 (개점 전에 로드뷰·지도·부대/학교 정보로 채운다)

### 군부대 — 높음 조건 셋 다
1. **부대 종류**: 사단 예하 보병 연대·신병교육대·훈련소처럼 **병사가 많고 외출·외박이 잦은 부대**. 사령부·특수부대·공군 비행단은 간부 중심이라 아님.
2. **정문 도보권**: 부대 정문에서 매장까지 **걸어서 1km 안**. 차를 타야 하면 아님.
3. **군인 상권 표식**: 로드뷰에 PC방 군인 정액제·군인 할인, 휴가 병사 대상 모텔·당구장·PC방 밀집.

이 프로젝트의 예: 금촌역·문산(1사단·9사단 보병 부대 앞) = 높음, 실측이 ×2.0·×2.5로 따라옴. **증평** = 37사단 **사령부**·13특임여단(특수부대) 소재지 → 1번 탈락 → 보통/낮음.
유동 성비로는 못 가른다(증평 남성 63%·문산 62%·금촌 59%).

### 대학가 — 높음 조건 (AI 프롬프트에 못 박은 정의)
1. **학부 중심 종합대학, 재학생 1만 명 이상**. 약대·의대 캠퍼스·연구단지·행정타운·전문대 소규모 캠퍼스는 아님(오송이 이 함정).
2. **정문·후문 도보권**에 **원룸촌**이 있다(주민등록 밖 학생이 사는 곳).
3. 학생이 주 고객.
- 참고: 대학가는 **방학에 안 뛴다**(방학÷학기 1.019, 일반 상권 1.178). 연평균을 맞히므로 배수가 1.3에 그친다.
- 강릉교동은 강릉원주대 1.1km·재학생 1만 미만·원룸촌 정문 생활권 아님 → 대학가 아님(교동택지 번화가라 관광유흥).

### 산업단지 — 높음 조건
1. 산단 **정문 생활권**(도보권)에 근로자 기숙사·원룸이 있다.
2. 유동 남성 비율이 높다(정왕 66%, 전체 중앙 57%).
- 정왕·광주첨단 = 높음(함의 1.45·1.69). 탕정역(삼성디스플레이 근처 신도시 주거) = 보통(함의 1.00). 호구포역(후보) = 낮음.
- 창원상남처럼 산단이 2~3km 밖이고 근로자가 번화가로 오는 경우는 **관광유흥**이지 산업단지가 아니다(퇴근 근로자는 유동에 있다).

### 관광유흥 — 높음 조건
1. 술집·노래방·유흥업소가 **밀집한 번화가 한복판**(로드뷰로 보인다). 관광지·터미널·역세권 유흥가 포함.
2. 유동인구가 크다(500m 10만 이상이 보통).
- 높음: 수원인계·야당·부천상동역(상동역 유흥가)·강릉교동(터미널 200m·교동택지)·창원상남·울산삼산·신중동·구리돌다리. 보통: 평택소사벌.
- 유동 20대 비중은 유흥가 중앙 10%로 대학가(18%)와 다르다 — 젊은 층이 많다고 대학가로 보지 말 것.

### 기타
혁신도시 공공기관 통근(진주혁신·남악), 역세권 상업(야탑·발산역·송도) 등. 배수 없음. "무엇인지는 알겠는데 넷이 아님"일 때.

## 4. 산식 두 벌이 강도를 다르게 본다 (2026-09-25 현재)

- **실험실(교과서식)**: 유형 + **높음** → 배수. 보통·낮음 = 0. `textbookModel.specialDemandHighOnly`.
- **운영 V62**: 군부대·산업단지를 **강도 무관 0/1 더미**로 학습(`calc.ts isBackingDemandMarket`). 관광유흥·대학가는 학습에 안 씀.
  → 증평(군부대/보통)을 사실대로 넣자 더미가 켜져 계수가 내려갔다(V62 MAPE 8.83→9.53, 후보지 −0.5~−1.7%). **다음 작업: V62 더미도 "높음만 1"로**(인계 문서 다음 할 일 0번).
