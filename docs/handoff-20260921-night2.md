## 1. ⭐ 오늘 채택한 것 — 지수 눈금 보정

```ts
indexCalibration: { ratioExponent: 0.327, locationExponent: 0.169, referenceUtilization: 0.3011 }
```

### 뭘 하는가

**전 매장 같은 곡선 하나**로, 예측을 가운데(30.1% = 기존점 실측 기하평균)로 당긴다.

| 원래 값 | 보정 후 | 배율 |
|---|---|---|
| 8% | 19.5% | ×2.44 |
| 16% | 24.5% | ×1.53 |
| **30.1%** | **30.1%** | **×1.00** |
| 40% | 33.0% | ×0.83 |
| 60% | 37.7% | ×0.63 |

⚠️ **매장별로 맞춘 게 아니다.** 쓰이는 수는 `0.327`과 `0.3011` **둘뿐**이다
(사용자 확인: *"매장마다 수요를 값에 맞추려고 하지 말고 일관된 산식으로"*).

### 왜 정당한가

사용자 정리: *"수요 > 가동률 이 산식이 현재 검증 가능한 부분이 없으니까
값에 맞추는 형태로 하는 게 최선이라고 보긴 함."*

수요도 총공급도 **우리가 만든 지수**다(총공급 = 자사PC + Σ경쟁PC×품질비³×거리무게 —
날PC수는 자사 것뿐). 실측할 방법이 없으니 **눈금을 실측 가동률에 맞춰 새기는 것**이
정직한 형태다. b<1은 "그 지수가 매장 간 차이를 과장한다"는 뜻이다.

### 성적

|  | MAE | 최악(%p) | ±5%p |
|---|---|---|---|
| 바꾸기 전 | 6.33%p | 16.6%p | 17/38 |
| 전부 훈련평균 | 4.38%p | — | 26/38 |
| **바꾼 뒤** | **4.03%p** | **12.8%p** | **28/38** |

**'전부 평균'을 처음으로 이겼다.**

⚠️ 퍼짐이 반대로 넘어갔다 — 예측 SD 8.15 → **3.01%p**로 실측(5.72%p)의 0.53배다.
전에는 1.42배 넓었다. 오차 최소화의 수학적 귀결이지만 **매장 간 차이를 작게 말한다**.
후보지 줄세우기에는 약점이다(순위는 유지, r=0.527).

### 후보지 영향

검증범위 밖이던 4곳이 전부 범위 안으로 들어왔다(외삽 0곳):
창원상남 7.8→21.3% · 영월 8.6→21.1% · 울산삼산 13.5→24.5% · 춘천퇴계 16.9→27.3%
최고÷최저가 4.7배 → 1.6배.

**사용자 확인: "후보지표도 얼추 맞는 듯."**

## 4. ⚠️ 남은 이상한 점 — **입지배율** (다음에 팔 자리)

사용자가 짚었다: *"호구포역점 점유율 왜 100%임? 경쟁점 있는데"*, *"영월점도"*.

```
호구포역  우리 품질 3.85 vs 워너비PC 1.99 → 품질비 0.517
          θ=3이면 123대가 **16대**로 세짐 → 85:15 → 입지 곱해 101.3% → 잘림
영월점    우리 3.90 vs I&G 2.44 → 품질비 0.626
          **θ=1.5부터 이미 잘린다** — 입지배율 **2.054**가 더 큰 원인
```

θ는 자료가 3을 지지하므로 못 내린다. 그러면 **영월 입지배율 2.054**가 남는다 —
주거 1만 명짜리 소도시에서 "동네 평균보다 2배 좋은 자리"가 맞는 값인지 의심스럽다.

## 7. 오늘 배운 함정

1. **단위를 섞지 마라** — SD는 %p, 최악은 상대%로 찍어 놓고 "오차폭은 주는데 최악이 는다"는
   모순을 만들었다. 사용자가 잡아 줬다. 같은 자로 보면 최악도 16.6 → 12.8%p로 준다.
2. **되맞춤 관문을 박아라** — "내가 뽑은 변수가 산식과 같은가"를 검사하는 관문이
   40% 어긋남으로 걸려서, 점유율 상한을 놓친 걸 잡았다.
3. **순환 검사를 조심하라** — 상한 검사를 `b.share ÷ 입지배율`로 하면 잘린 값을 되나눠
   정확히 1이 되므로 **영영 안 걸린다.** 경쟁점에서 직접 만들어야 한다.
4. **내가 "물리적으로 확실하다"고 한 게 틀렸다** — 공급 지수 −1. 총공급도 구성 지수였다.
5. **입지를 점유율 밖으로 빼자는 제안도 틀렸다** — 사용자가 잡아 줬다.
   *"입지 때문에 수요가 늘어나진 않잖아."* 입지는 점유율에 작용하고 100% 상한도 옳다.
