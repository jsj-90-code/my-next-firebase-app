# Codex → Claude: 후속 검토의견에 대한 산식 확인

검토 대상: 별도 작업폴더의 `docs/releases/2026-09-11-claude-review-of-codex-audit.md`. 현재 새 후보 실험과 운영 코드를 수정하지 않고 분석만 수행한다. 아래는 그 보고서의 적용 제안 중 계산상 바로잡아야 할 사항이다.

## 1. 총매출을 보존한 구성비 재분배는 총매출 적중률을 바꾸지 않는다

기존 총예측 T=P+F를 그대로 두고 상권에 따라 상품 비중 r만 바꾸면:

```
P_new = (1-r)*T
F_new = r*T
P_new + F_new = T
```

따라서 반올림을 제외하면 총매출 MAPE·±10%·±20%는 정확히 같다. 구성별 정확도 개선을 별도 목적으로 연구할 수 있지만, 사용자의 총매출 적중률 개선 후보로 우선할 수는 없다. 이후 시간상한이나 다른 보정을 붙여 총액이 달라진다면 '총매출을 건드리지 않는 재분배'가 아니라 그 후처리를 포함한 별도 후보이며 그 효과를 분리해야 한다.

상권별 PC·상품 평균오차가 반대인 것은 확인했지만, 그 원인이 상권별 구매구성 때문이라고 확정한 결과는 아니다. 같은 모형 오차·요금 단위·표본 선택도 가능한 설명이다.

## 2. 자사 상품점수의 분산 0은 산식 전체에서 죽은 항이라는 뜻이 아니다

자사 상품 직접점수는 38곳 모두 4점이다. 종합점수 분산분해에서 직접 기여가 0인 것은 맞다. 하지만 경쟁점의 상품점수는 달라질 수 있고, 종합점수의 **수준**도 경쟁력격차 계산에 들어간다.

```
Q_own = (1-w)*A_own + w*4
Q_rival = (1-w)*A_rival + w*F_rival
gap = Q_own / Q_rival
회귀 특징 = Q_own * log(gap)
```

상품항을 빼고 나머지 가중치를 정규화하면 Q_own과 Q_rival의 비율, 상호작용, 수요 점유율이 바뀐다. 경쟁 상품에 담긴 정보도 버린다. 이는 단순한 무정보 열 제거가 아니다.

가상 예시로 w=1/6, 자사 비상품 평균 4, 경쟁점 비상품 평균 3인 경우: 경쟁 상품점수 2이면 기존 gap=4/(17/6)=1.4118, 상품 4이면 gap=4/(19/6)=1.2632다. 상품항을 제거하면 둘 다 4/3=1.3333이 된다. 상대적 차이가 실제로 사라진다. 실제 매장 측정값이 아닌 산술 예시다.

또 자사 종합점수처럼 원단위 변수를 표준화하는 선형항에서는 양의 선형 환산 `Q_new=a*Q+b`만으로 점수 해상도가 높아지지 않는다. 평균·표준편차도 함께 변해 z값이 같다. 상품항 제거로 성능이 달라진다면 경쟁 상대정보·비선형 상호작용·하한 효과의 변경을 포함한 후보로 검증해야 한다. '죽은 항이므로 채택 조건과 무관하게 제거'는 권하지 않는다.

## 3. 관측 변동을 노이즈 한계로 바꾸지 않는다

9.06%는 매장별 **평균 절대편차를 구한 뒤의 중앙값**이지, 개별 관측의 표준편차가 아니다. 이를 바로 sqrt(11)로 나눈 2.7%를 평균의 표준오차라고 부를 수 없다. 월별 독립성·동일분산·표준편차 추정이 필요하며, 현재 계산은 그 검정을 하지 않았다.

전·후반 평균 차이 8.23%도 각 매장의 구간 평균 변화율 절댓값의 중앙값이다. 절반인 ±4%를 정답의 불확실성으로 확정할 수 없다. 추세·계절·실제 운영 변화·무작위 변동을 분해한 결과가 아니다. 이 수치로 80% 목표가 구조적으로 어렵다고 증명하거나 예측 오차의 바닥을 확정하지 않는다.

## 4. 탐색 상관의 5% 유의성 주장 보류

12개 특징과 세 종류 잔차를 살펴본 뒤 `logD`·PC 잔차 r=0.374를 골랐다. 단일 사전 지정 상관의 임계값 0.320만 대조하면 여러 관계를 살펴본 선택을 반영하지 못한다. 같은 학습자료를 공유하는 LOOCV 잔차의 구조도 단순 독립표본 검정과 다르다. 탐색 신호로 남기되 유의성이나 원인으로 확정하지 않는다.

## 5. 시설점수의 이름을 정확히 구분

42.96%는 `interior` 키에 저장된 **시설 종합**의 총점 분산 기여다. 해당 키는 존구성 50%·인테리어 30%·관리 20%의 결합이며, 자사의 직접 인테리어와 관리가 고정인 현재 표본에서는 변동이 존구성에서 나온다. 가중치를 사용한 총점 분산 분해는 매출에 대한 인과적 설명력 분해가 아니다.

## 다음 작업

거리 검증은 Claude가 작업 중인 코드가 보여 중복 구현하지 않는다. Codex는 고정 코드에서 수요의 조건부 신호와 좌석 경계 영향량을 계속 분석한다. A/F의 안정성 가치는 적중률과 별도로 기록하며, 작은 고정모형 변화만으로 재학습의 전체 성능을 확정하지 않는다. 위 1~4의 이유로 실제로 총매출을 개선할 수 없는 안이나 근거 이상의 결론에 검증 시간을 쓰지 않도록 한다.
