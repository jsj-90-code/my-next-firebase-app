# 총매출 공통 보정 후보 검증

2026-09-11 · 결과 확인 전 설계. 기존 가중치 후보와 결합하지 않는다.

기존 PC·상품 내부 교차보정을 유지한 상태에서, 외부 평가점포를 제외한 훈련자료 안의 OOF 총매출 예측으로 공통 배율 c 하나를 구한다. 내부 OOF 모형의 기존 교차보정에서도 해당 내부 평가점포를 제외한다. 두 성분의 학습 절편에 log(c)를 더하고 중앙값 기준도 c배로 바꿔 기존 이용시간 상한과 성분별 반올림을 다시 계산한다. 총액 표시만 바꾸지 않는다.

비교 후보는 두 개로 고정한다.

- 총매출 MAPE 보정: 기존 `crossFittedCorrection`을 총매출 OOF 예측·실적 쌍에 적용한다. 기존 함수와 같은 가중 중앙값 절반 이동이며 별도 강도는 탐색하지 않는다.
- ±10% 바깥 오차 보정: 평균 `max(0, abs(c*예측/실제-1)-0.1)^2 + (c-1)^2`를 최소화한다. 기존 제안의 log(c) 페널티 대신 배율 자체의 제곱 페널티를 사용해 양수 배율에서 볼록한 1변수 문제로 만든다. 페널티 계수 1은 결과 확인 전 고정하며, 외부 평가 성능으로 조정하지 않는다. 목표와 달리 적중 개수를 직접 최대화하는 방식은 아니다.

1477c23 고정 코드·2026-09-09 보존자료 38곳에서 기존 LOOCV를 재현하고 두 후보를 비교한다. 기존 k=2.46과 설정은 고정하며, 과거 후보 탐색에 같은 표본을 쓴 한계는 남는다. 총매출 MAPE·±10%·±20%·최악 오차를 함께 확인한다. 양호한 후보가 있으면 반복 분할을 추가하며 그렇지 않으면 이 두 보정안의 검토를 종료한다. 운영 변경은 포함하지 않는다.

1차 LOOCV에서 두 후보의 ±10%가 늘고 ±20%가 유지되어, 같은 시드 흐름 9112026의 반복 5분할 20회로 안정성을 확인한다. 각 분할의 보정도 해당 훈련자료 내부의 OOF에서 새로 추정한다. 새 후보나 조합 탐색은 추가하지 않고 결과를 정리한 뒤 Claude에 이관한다.
