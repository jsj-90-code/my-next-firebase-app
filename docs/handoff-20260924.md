## 1. ⭐⭐ 오늘 찾은 것 — **지는 건 경쟁 센 절반뿐이다**

```
  무리              산식 MAE   전부평균   퍼짐    분별력 r   판정
  전체               5.85%p    4.82%p   1.32배   0.516    ⛔ 진다
  경쟁 약한 절반        4.68%p    5.63%p   1.17배   0.628    ✅ **이긴다**
  경쟁 센 절반         7.01%p    4.16%p   1.54배   0.434    ⛔ 진다
```

**산식 전체가 과장하는 게 아니다. 경쟁 항이 과장한다.** 수요 쪽은 독점매장에서 이미 맞고,
경쟁 약한 절반에서는 바닥까지 이긴다. 범위를 안 좁히면 멀쩡한 층을 건드리게 된다.

재는 자리: `_underPredicted.test.ts` **(L)번**.

### ⭐ 이기는 조건은 산수로 정해져 있다

제곱오차 기준으로 '전부 평균'을 이기려면 **분별력 r > 퍼짐 ÷ 2** 여야 한다.
지금 퍼짐 1.32배이므로 **r > 0.659**가 필요하고, 지금은 0.516이다. 길은 둘뿐이다:

1. **분별력을 올린다** (0.516 → 0.66 위로)
2. **퍼짐을 줄인다** (r배까지) — ⚠️ 기전 없이 하면 그게 어제 끈 눈금 보정 b다

### ⭐ 그리고 천장은 멀다 — 실측값에는 잡음이 거의 없다

평가창의 달을 홀/짝으로 반 갈라 재 봤다:

```
  반쪽끼리 상관 r      0.987
  전체 평균의 신뢰도    0.993   (스피어만-브라운)
  분별력 천장 = √신뢰도  0.997
  매장 안 달별 흔들림   log SD 0.121  vs  매장 사이 퍼짐 log SD 0.213
```

**r=0.516은 천장에 눌린 게 아니다.** 못 잡은 신호가 아직 많이 남아 있다.

## 3.5 ⭐⭐⭐ 점유율 100% 잘림을 파서 나온 것 — **목표가 숫자로 나왔다**

사용자(2026-09-24): *"현재 문제로 보이는 건 산식 점유율 부분인 거 같아. 구미산동점 점유율
100퍼 뜨는 거, 문경시청점 100퍼 뜨는 거 등 문제 있는 거 아닌가?"*

**지적이 맞았다. 다만 자름 자체는 병이 아니라 표시등이었다.**

### 자름은 입지 항이 만든다 — 그리고 풀어도 성적이 안 바뀐다

```
  매장        경쟁만의몫  x입지^0.5  =원래값  ->잘린값  버린몫   예측 -> 실측
  구미산동점      74.1%     1.375    101.8%   100.0%   1.8%p   28.9% -> 20.9%
  문경시청점      78.7%     1.288    101.4%   100.0%   1.4%p   19.4% -> 30.6%
```

`rawShare = 자사PC ÷ (자사PC + 경쟁점)`은 **구조상 1을 못 넘는다.** 자름이 무는 건
**입지 항이 곱해질 때뿐**이다. 그리고 자름을 풀면 MAE 5.85 → 5.85%p, r 0.516 → 0.514로
**아무것도 안 바뀐다**((R)번 재고 표).

### 표시등이 가리킨 것 — 필요 점유율

**필요 점유율 = 실측 ÷ (수요/좌석)**. 100%를 넘으면 동네 수요를 다 먹어도 실측에 못 미친다.

```
  ⛔ 100%를 넘는 매장 2곳 — 문경시청 158% · 양주덕정 101%
  분포: 중앙 42% · 범위 20~158%
```

**그 두 곳은 점유율을 아무리 고쳐도 못 맞힌다. 고칠 자리는 수요다.**

### ⭐ 그런데 점유율 층은 과장하지 않는다

```
  산식 점유율 vs 필요 점유율    r = 0.838
  퍼짐 0.427 vs 0.448         과장 **0.95배** (오히려 살짝 좁다)
  점유율 층이 필요 점유율의 분산을 설명하는 몫  **69%**
```

수요 쪽도 눌러 봤다 — 퍼짐을 α제곱으로 줄이면 r이 0.516 → 0.159로 **계속 떨어진다**((T)번).
**두 층 다 제 눈금이다.** 어느 쪽도 눌러선 안 된다.

### ⭐⭐ 그럼 왜 지나 — 오차 예산으로 풀린다

```
  맞히려는 것 — 실측 가동률        log SD 0.213
  수요/좌석 (양쪽에 공통)          log SD 0.438
  필요 점유율 (수요를 되돌려야 함)   log SD 0.448   ← 맞히려는 것보다 2.1배 크다
  산식 점유율                     log SD 0.427
  남는 오차 = 필요 − 산식          log SD 0.250   ← 실측 퍼짐 0.213보다 **크다**
```

`log(실측) = log(수요/좌석) + log(필요 점유율)` 이고 `log(예측) = log(수요/좌석) + log(산식
점유율)` 이라 **수요 항은 양쪽에 똑같이 들어간다.** 오차는 정확히 `필요 − 산식`이다.

산식은 **크고 서로 반대로 움직이는 두 수를 곱해 작은 수를 만들려고 한다.**
점유율 층이 필요 점유율의 69%를 맞히는데도, 못 맞힌 31%(SD 0.250)가 **답 자체의
퍼짐(0.213)보다 커서** 바닥에 진다.

### ⭐⭐⭐ 그래서 목표가 숫자로 나왔다

> **점유율 층 잔차 SD를 0.250 → 0.213 아래로.** 14.8%만 줄이면 '전부 평균'을 이긴다.
> (같은 말: 점유율 층 설명력 **69% → 77.4%** 위로)

`r > 0.659`보다 이 자가 훨씬 쓸모 있다 — **어디를 고쳐야 하는지가 붙어 있기 때문이다.**
재는 자리: **(S)(T)번**.

## 4. 🟡 남은 갈래 — 경쟁 센 절반의 과대예측

상황이 이렇게 좁혀졌다:

- 경쟁 센 절반은 **과대예측**이다(시흥배곧 48.0→36.0 · 일산탄현 46.2→32.9 · 금촌역 45.7→36.5)
- 과대예측 = 분모가 작다
- 그런데 **경쟁점을 더 넣으면 분별력이 무너진다**(3절)
- 감쇠를 넓혀 더 세도 무너진다(3절)

**그러면 남는 건 "경쟁점 낱개의 크기·품질이 틀렸다"는 쪽이다.** 개수가 아니라 **하나하나의
무게**다. 다음 세션이 팔 자리:

1. **경쟁점 품질점수의 눈금.** 아는 경쟁점들의 품질비(경쟁÷자사) 기하평균이 **0.581**이다 —
   θ=3이면 경쟁점 한 곳이 **0.196배**로 쪼그라든다. 우리 가맹점이 정말 경쟁점보다
   그 정도로 나은가? 이건 **자사 시설점수 4점 고정**과 맞물린 자리다
   (전 매장 같은 값인 건 "오픈 1년 시점 평가"라서 정상이다 — 최신성으로 바꾸자는 얘기가 아니다).
   ⚠️ 품질을 아는 경쟁점이 **중앙 97%**라 "모르는 쪽만 유리하게 센다"는 비대칭은 작다.
   중립값을 표본 기하평균(0.581)으로 옮겨 봐도 r 0.516→0.542로 조금 오르고 MAE는 나빠진다((Q)번).
2. **경쟁점 PC 대수를 낱개로.** 지금 미조사는 전부 90대다. 소형 경쟁점 조사는 여전히
   값어치가 있지만 **'전부 평균' 넘기의 지렛대는 아니다**(3절에서 2km 쪽으로 확인).
   경쟁 센 절반의 분모는 **조사된 500m 경쟁점**이 96%를 채운다 — 거기 대수가 맞는지부터다.
3. **독점 3곳 원장** — 받으면 수요층을 직접 볼 수 있다(어제부터 열려 있음).
