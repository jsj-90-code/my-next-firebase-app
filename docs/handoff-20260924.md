## 3.5 ⭐⭐⭐ 점유율 100% 잘림을 파서 나온 것 — **목표가 숫자로 나왔다**

사용자(2026-09-24): *"현재 문제로 보이는 건 산식 점유율 부분인 거 같아. 구미산동점 점유율
100퍼 뜨는 거, 문경시청점 100퍼 뜨는 거 등 문제 있는 거 아닌가?"*

**지적이 맞았다. 다만 자름 자체는 병이 아니라 표시등이었다.**

### 자름은 입지 항이 만든다 — 그리고 풀어도 성적이 안 바뀐다

```
  매장        경쟁만의몫  x입지^0.5  =원래값  ->잘린값  버린몫   예측 -> 실측
  구미산동점      74.1%     1.375    101.8%   100.0%   1.8%p   28.9% -> 20.9%
  문경시청점      78.7%     1.288    101.4%   100.0%   1.4%p   19.4% -> 30.6%
```

`rawShare = 자사PC ÷ (자사PC + 경쟁점)`은 **구조상 1을 못 넘는다.** 자름이 무는 건
**입지 항이 곱해질 때뿐**이다. 그리고 자름을 풀면 MAE 5.85 → 5.85%p, r 0.516 → 0.514로
**아무것도 안 바뀐다**((R)번 재고 표).

### 표시등이 가리킨 것 — 필요 점유율

**필요 점유율 = 실측 ÷ (수요/좌석)**. 100%를 넘으면 동네 수요를 다 먹어도 실측에 못 미친다.

```
  ⛔ 100%를 넘는 매장 2곳 — 문경시청 158% · 양주덕정 101%
  분포: 중앙 42% · 범위 20~158%
```

**그 두 곳은 점유율을 아무리 고쳐도 못 맞힌다. 고칠 자리는 수요다.**

### ⭐ 그런데 점유율 층은 과장하지 않는다

```
  산식 점유율 vs 필요 점유율    r = 0.838
  퍼짐 0.427 vs 0.448         과장 **0.95배** (오히려 살짝 좁다)
  점유율 층이 필요 점유율의 분산을 설명하는 몫  **69%**
```

수요 쪽도 눌러 봤다 — 퍼짐을 α제곱으로 줄이면 r이 0.516 → 0.159로 **계속 떨어진다**((T)번).
**두 층 다 제 눈금이다.** 어느 쪽도 눌러선 안 된다.

### ⭐⭐ 그럼 왜 지나 — 오차 예산으로 풀린다

```
  맞히려는 것 — 실측 가동률        log SD 0.213
  수요/좌석 (양쪽에 공통)          log SD 0.438
  필요 점유율 (수요를 되돌려야 함)   log SD 0.448   ← 맞히려는 것보다 2.1배 크다
  산식 점유율                     log SD 0.427
  남는 오차 = 필요 − 산식          log SD 0.250   ← 실측 퍼짐 0.213보다 **크다**
```

`log(실측) = log(수요/좌석) + log(필요 점유율)` 이고 `log(예측) = log(수요/좌석) + log(산식
점유율)` 이라 **수요 항은 양쪽에 똑같이 들어간다.** 오차는 정확히 `필요 − 산식`이다.

산식은 **크고 서로 반대로 움직이는 두 수를 곱해 작은 수를 만들려고 한다.**
점유율 층이 필요 점유율의 69%를 맞히는데도, 못 맞힌 31%(SD 0.250)가 **답 자체의
퍼짐(0.213)보다 커서** 바닥에 진다.

### ⭐ 목표는 숫자로 나왔다 — ⚠️ **다만 "점유율을 고쳐라"는 아니다**

> **잔차 SD를 0.250 → 0.213 아래로.** 14.8%만 줄이면 '전부 평균'을 이긴다.

⚠️ **2026-09-24 자기검토에서 정정한 것.** 처음엔 이걸 *"점유율 층 잔차"*라고 불렀는데,
**그건 국한이 아니라 항등식이었다.** 필요 점유율을 `실측 ÷ (수요/좌석)`으로 **정의**했으니
`필요 − 산식 = log(실측) − log(예측)` = 산식 전체의 잔차다. 실제로 재 보니 두 값이
**SD 0.2495로 완전히 같고 상관 1.0000**이다((V) 검토 1).

그래서 맞는 말은 이렇다:
- ✅ **이기는 조건**: 잔차 SD 0.250 → 0.213 아래 (= `r > 퍼짐 ÷ 2`와 같은 말)
- ✅ **구조에 대한 관찰**: 필요 점유율의 퍼짐(0.448)이 맞히려는 답(0.213)보다 **2.1배 크다.**
  산식은 크고 서로 반대로 움직이는 두 수를 곱해 작은 수를 만들려 한다
- ⛔ **못 하는 말**: "오차가 점유율 층에 있다". 수요 추정이 틀리면 필요 점유율이라는
  **과녁 자체가 틀린 것**이고, 그 오차도 똑같이 저 잔차에 들어온다

재는 자리: **(S)(T)(V)번**.

## 3.7 🟡 자기검토에서 새로 나온 것 — **입지 지수 0.5는 분별력을 팔아 산 것이다**

(G)에서 입지를 얼려도 **분별력 r이 0.516 그대로**였다. 이상해서 지수를 다시 훑었다((V) 검토 3):

```
  지수     MAE      퍼짐    분별력 r   순위 분별력
  0.000   6.72%p   1.54배    0.516      0.569
  0.169   6.26%p   1.44배    0.525      **0.584**  ← 순위 분별력 최고 (어제까지의 값)
  0.300   5.97%p   1.38배    **0.526**   0.575     ← r 최고
  0.500   5.85%p   1.32배    0.516      0.544     ← **MAE 최고. 지금 값**
  0.750   6.13%p   1.31배    0.495      0.522
  1.000   6.55%p   1.35배    0.456      0.518
```

**MAE는 0.5까지 계속 좋아지는데 분별력 두 자는 0.169~0.3에서 꼭지를 찍고 내려간다.**
즉 0.169 → 0.5는 **분별력을 팔아서 MAE를 산 거래**다. 어제 채택 주석에도 그 맞바꿈이
적혀 있고(*"분별력 손실은 잡음 수준"*) 사용자가 그 값을 골랐다 — **결정을 뒤집자는 게 아니다.**

다만 오늘 새로 생긴 자(`r > 퍼짐 ÷ 2`)로 다시 보면 이렇다:

```
  지수     r      퍼짐÷2   남은 거리
  0.169   0.525   0.72    −0.195
  0.300   0.526   0.69    −0.164
  0.500   0.516   0.66    **−0.144**  ← 지금. 이기는 데 제일 가깝다
  1.000   0.456   0.675   −0.219
```

**0.5가 여전히 제일 낫다.** 다만 이기는 쪽으로 가까워진 이유가 **퍼짐을 줄여서**지
분별력이 늘어서가 아니다. ⚠️ 이건 오늘의 큰 그림과 맞물린다 — **오늘 재 본 모든 손잡이가
"누르기"였고, 분별력을 올린 건 하나도 없었다.**

> *"인테리어는 가맹점 평가는 똑같아야 함. 왜냐면 똑같은 컨셉에 똑같은 도면으로 작업한
> 거니까. 물론 구도 구성은 좀 틀린데 인테리어적인 측면은 같다고 보면 됨. 내가 말한 조정은
> **4점에서 일괄적으로 좀 내린다** 이런 걸 얘기한 거임. 먹거리도 마찬가지로 매장별 조정이

**인테리어·먹거리는 매장을 가를 수 없는 항목이다**(같은 도면 · 같은 프랜차이즈 메뉴).

손잡이가 아니라 수준 손잡이**다 — "경쟁점을 얼마나 세게 볼 것인가"를 정한다.

### ⭐ 그래서 다시 쟀다 — 기본값 수준

```
  자사 점수        MAE     편향   퍼짐  분별력r   품질비   ×배   남은거리
  5.0           6.38%p   +1.2%p  1.28배  0.507   0.548  0.165   −0.135
  4.5           5.99%p   +0.2%p  1.30배  0.512   0.564  0.179   −0.136
  4.0           5.85%p   −0.8%p  1.32배  0.516   0.581  0.196   −0.143  ← 지금
  3.5           6.01%p   −1.9%p  1.35배  0.519   0.598  0.214   −0.154
  3.0           6.33%p   −3.0%p  1.38배  0.522   0.617  0.235   −0.169
  2.5           6.71%p   −4.1%p  1.42배  0.523   0.637  0.259   −0.188
```

**중첩 LOO는 40겹 전부 4.0을 골랐다.** 자료가 만장일치다(눈금 보정 b가 떨어졌던 그 잣대다).

### ⭐⭐ 그런데 **θ와 같은 자리를 만진다** — 기본값은 뜻으로 정해도 된다

작용하는 건 **(품질비)^θ = ×배** 하나다. 기본값을 내리면 θ를 내려 되돌릴 수 있다.
각 기본값에서 θ를 다시 맞춰 봤다:

```
  기본값   제일 좋은 θ    MAE     퍼짐  분별력r   ×배    남은거리
   5.0       2.50      5.80%p   1.24배   0.484   0.222   −0.137
   4.5       2.75      5.81%p   1.28배   0.501   0.207   −0.137
   4.0       3.00      5.85%p   1.32배   0.516   0.196   −0.143  ← 지금
   3.5       3.25      5.94%p   1.37배   0.529   0.188   −0.155
   3.0       3.50      6.11%p   1.43배   0.541   0.185   −0.172
   2.5       3.75      6.35%p   1.50배   0.554   0.185   −0.195
```

**×배가 0.185~0.222로 거의 같다.** 둘은 서로 바꿔칠 수 있다는 뜻이다:

> **기본값은 현장 판단으로 정하고 θ가 그 자리를 메우면, 산식이 크게 안 상한다.**
> 4.0 → 3.0으로 내려도 θ 3.0 → 3.5면 MAE 5.85 → 6.11%p다.
> 그리고 **분별력은 오히려 오른다**(0.516 → 0.541) — 퍼짐이 같이 늘어서 총합은 손해지만.

### 📌 전례 — 관리는 이미 살아났다

관리도 원래 전 매장 4.00이었는데 2026-09-17에 **QSC로 갈아끼워** SD 0.53이 됐다
(`qscToManagementScore`). 끄면 r이 0.516 → 0.491로 떨어진다. 다만 관리는 **매장마다 진짜로
다른 것**(운영 상태)이라 갈아끼우는 게 맞았고, 인테리어·먹거리는 **같은 게 맞다.**

📌 사용자 확인: **원본 QSC 체크리스트에는 항목별 점수가 있다.** 다만 위 이유로
매장별로 쪼개 쓸 항목이 아니다 — 기본값 수준을 정하는 **근거**로는 쓸 수 있다.

## 4. 🟡 남은 갈래 — 경쟁 센 절반의 과대예측

무게**다. 다음 세션이 팔 자리:

1. **경쟁점 품질점수의 눈금.** 아는 경쟁점들의 품질비(경쟁÷자사) 기하평균이 **0.581**이다 —
   θ=3이면 경쟁점 한 곳이 **0.196배**로 쪼그라든다. 우리 가맹점이 정말 경쟁점보다
   그 정도로 나은가? 이건 **자사 시설점수 4점 고정**과 맞물린 자리다
   (전 매장 같은 값인 건 "오픈 1년 시점 평가"라서 정상이다 — 최신성으로 바꾸자는 얘기가 아니다).

   중립값을 표본 기하평균(0.581)으로 옮겨 봐도 r 0.516→0.542로 조금 오르고 MAE는 나빠진다((Q)번).
