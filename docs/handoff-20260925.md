## 1. ⭐⭐⭐ 새로 생긴 것 — **바깥 표본**

경쟁점 문서에 **핑봇 실측 가동률**(`pingbotUtilization`)이 있다. **57곳**이고 **전부 대수도
같이 있다.** 이걸 쓰면 판정 표본이 늘어난다:

```
  자사 매장  "우리 자리에 우리가"   평가창 실측 37곳  ← 계수를 맞출 때 쓴 **안쪽**
  경쟁점    "남의 자리에 남이"     핑봇 실측  47곳  ← 한 번도 안 쓴 **바깥**
  후보지    "남의 자리에 우리가"    실측 없음
```

경쟁점에 좌표·대수·품질이 다 있으니 **그 자리에 `computeTextbook`을 그대로 돌릴 수 있다.**
후보지 평가와 똑같은 계산을 **이미 답이 있는 자리**에서 검증하는 것이다.
✅ 검산 통과 — 자사 37곳 MAE **5.84%p**(평소 5.85%p와 일치).

**왜 중요한가:** 자사 40곳으로는 MAE 0.70%p 미만 차이를 못 가른다(`_underPredicted` (Z)).
핑봇은 더 못 모은다(사용자 확인). 그래서 **있는 걸 세게 쓰는 게 유일한 길**이었다.

재는 자리: **`_rivalAsSubjectFull.test.ts`** (본 산식판. 간이판 `_rivalAsSubject.test.ts`는
입지배율이 빠져 있으니 쓰지 말 것).

## 2. ⭐⭐ 문제 하나 — **수요가 1.5~2배 작다**

```
  산식이 함의하는 경쟁점 가동률   중앙 **8.7%**
  핑봇 실측                    중앙 **21.1%**  (57곳)
  우리 매장 실측                중앙  30.8%
```
PC방이 8.7%로는 장사가 안 된다. 동네 수요를 직접 재 보면(`_measuredDemand.test.ts`):
```
  실측 하한 ÷ 산식 수요      중앙 1.15배   ← 하한인데도 1을 넘는다
  커버리지 보정 ÷ 산식 수요   중앙 **1.99배**
```

### ⭐ 그런데 **패턴은 맞다**
```
  산식 수요 퍼짐(logSD) 0.277 · 실측(보정) 0.375 -> 산식이 오히려 **좁다**
  산식 수요 vs 실측(보정)  **r = 0.618**   (n=14)
```
"인구 데이터에 신호 없음"을 부분적으로 뒤집는다. **틀린 건 구조가 아니라 눈금이다.**

### 어느 항이 범인인가
```
  지금 그대로       배율 1.15배 · 퍼짐 0.411
  주거 반경 500m    배율 1.86배 · 퍼짐 **0.344**  ← 실측과 제일 잘 맞는 모양
  유동 x0.30        배율 0.80배 · 퍼짐 0.390
  상권 흡인력 a=0.3  배율 0.76배 · 퍼짐 0.449   ← 나쁘다
```
⚠️ **자사 매출 기준으로는 1km가 이겼었다** — 잣대가 다르면 답이 다르다.
⚠️ 흡인력은 자사 가동률 r은 올리는데(0.504→0.542) **실측 수요 기준으로는 나쁘다.** 상충한다.
⚠️ `hoursPerUserPerMonth`(8.20h)는 **원장 실측**이라 못 건드린다. 고칠 자리는 **이용자 수**다.

## 3. ⭐⭐⭐ 문제 둘 — **자사 품질이 후하다**

같은 동네에서 우리 ÷ 경쟁점 가동률(29곳):
```
  실측 격차  중앙 **1.49배**
  예측 격차  중앙 **3.50배**   -> 2.35배 과장
```
사용자 증언과 맞는다(탕정역: *"우리 매장이 경쟁력 제일 떨어짐. 관리 부분 제외하고"*).

### θ 하나로는 설명이 안 된다
```
  짝 과장(경쟁점끼리 + 자사 섞임)  1.66배
  자사우위 과장(자사-경쟁점만)     **2.35배**   ← 자사가 낀 쪽이 더 부푼다
```
θ 때문이면 둘이 똑같이 부풀어야 한다. **자사 점수 자체가 후하다.**

### 항목별로 바깥 표본이 검증했다 (경쟁점 47곳끼리 — 자사 편향이 안 낀다)
```
  항목      비중    평균   SD     핑봇 가동률과 r
  사양     26.4%   2.60  0.57       0.180
  먹거리     7.5%   2.63  0.47      −0.028
  존구성    23.8%   1.39  0.69       0.066
  인테리어   10.2%   2.68  0.54       0.011
  관리     15.1%   2.55  0.73       0.198
  (유의선 ±0.29 — **넘은 항목이 하나도 없다**)
```

**존구성은 사용자 설명대로 이분법이다** — 1.2 이하가 33/47곳(70%).
```
  룸 있는 쪽 14곳 20.8%  vs  룸 없는 쪽 33곳 20.1%
  차이 0.6%p (2SE 5.0%p) -> **자료가 차이를 못 본다**
```

### 항목을 끄면
```
  끈 항목     경쟁MAE  경쟁r | 짝과장 | 자사우위 실측/예측
  안 끔       12.6%p  0.235 | 1.66배 | 1.49/**3.50**배   ← 지금
  존구성      11.6%p  0.208 | 1.40배 | 1.49/**2.45**배   ← 여러 지표 개선
  사양        13.0%p  0.208 | 1.88배 | 1.49/4.24배
  인테리어     13.0%p  0.249 | 1.76배 | 1.49/3.87배
```

⚠️ **존구성을 통째로 꺼도 2.45배로 여전히 1.6배 과하다.** 존구성만의 문제가 아니다.

### ⭐ 사용자가 준 기전 — 구조가 다를 수 있다
> *"PC방은 친구들과 함께 오는 곳이니까 팀룸이 수요가 있지. **팀룸 하러 왔다가 자리 없으면
> 일반석에 앉는다**던가 그런 구조가 있다고 느껴짐."*

그러면 팀룸은 **유입 장치**이고 효과가 **매장 전체 가동률**로 나타난다.
그런데 지금 존구성은 **점유율(품질) 항**에 들어가 있다. 대표님 설명대로면 **수요 쪽**에
가깝다. **구조가 다르다** — 다음 세션이 팔 자리다.

### ⚠️ 시점 교란은 작다 — 사용자 확인
> *"리뉴얼하는 경우는 거의 없어서. 있을 수도 있는데 감안해서 봐야 할 듯."*
> *"다만 비교데이터가 오픈 후 1년이라 거의 없다고 봐도 무방할 듯."*

경쟁점 품질은 우리 매장 오픈 당시 조사값이고 핑봇은 2026-08이다. **매장에 따라 1~3년
차이**가 난다(2023년 오픈 매장이 제일 크다). 다만 **리뉴얼 자체가 드물어서** 교란은 작다고
본다 — 그래도 0은 아니니 결론을 낼 때 한 번 더 감안할 것.
📌 **다시 열 때 할 일**: 오픈 연도별로 갈라서 상관을 재 보면 교란 크기가 나온다.
2023년 오픈 매장의 경쟁점만 따로 보면 시점 차가 제일 크다.

## 4. ⭐⭐ 둘은 **독립**이고, 같이 고치면 둘 다 잡힌다

```
  자사 품질만 ×0.75  ->  자사우위는 맞아가는데 **자사 편향 −12%p**
  수요만 ×2.0        ->  경쟁 편향은 잡히는데 **자사 편향 +19%p**
  ⭐ 같이           ->  수요 ×1.5 · 자사품질 ×0.8  =>  자사 **+0.6%p** / 경쟁 **−3.1%p**
```
`수요 ×1.5 · 자사품질 ×0.75`에서: 자사MAE 7.38%p · r 0.470 · 짝과장 1.26배 ·
자사우위 1.49/**1.63**배(지금 3.50배).

치르는 값: 자사 MAE 5.84→7.38%p · 짝적중 76→68%.
**전형적인 과적합 해소 패턴이다** — 안쪽이 나빠지고 바깥이 좋아진다.

⛔ **채택 제안이 아니다.** 두 배수 다 **진단용**이다. 실제로는
(가) 이용자 수를 키우는 정당한 경로 (나) 어느 품질 항목이 후한지 — 를 찾아야 한다.
