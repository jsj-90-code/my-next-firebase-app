### 6. 측정기 화면(`src/app/ping-monitor/page.tsx`, `src/lib/pingMonitor/summary.ts`) 가독성·로직
- 상태: **측정 중 / 과응답·IP 확인(일일평균 60% 초과, 라이브) / IP·핑차단 확인 / IP 확인 전 / IP 미등록 / 첫 측정 대기**. "측정값 확인 필요"·"측정 불가 의심" 문구는 폐기.
- **정렬**: 측정 중(위) → IP 있는데 안 됨 → IP 미등록(아래), 각 묶음 거리순.
- **측정 안 되는 매장은 가동률 칸 전부 "-"**(0%·대·시간치·수집중 숨김). 단 **실측 일일평균 1% 이상이면 꼬리표보다 실측 우선**(데이터 뜨면 무조건 표시). 1% 미만 스침은 "-"(카사·화명크라우드).
- 칸: 거리·대수·**실시간**(마지막 회차 켜진수/대수·N대)·오늘·24시간(수집 전 "수집중")·이번주(N일치)·**이달 월 가동률**·상태.
- "N대"(≈동시 켜진 PC = 손님 규모)는 **실시간에만**. 헤더 한 줄(라벨+날짜 괄호). N일치·시간치는 % 옆 인라인.
- 폐업·중지 매장 목록에서 숨김(숨긴 수만 표시). 최근24시간 **22칸**으로 완화 + 거른 시각 배너.
