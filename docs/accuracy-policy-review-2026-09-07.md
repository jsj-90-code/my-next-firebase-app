# 실매출 기반 점수 보정·검증 기준 재검토

사용자는 2026-09-07 합리적인 실매출 기반 점수 변경과 검증 기준 재검토를 허용했고,
Claude를 함께 사용하도록 지시했다. 기존 무조건적인 최악 오차 비악화 요구를
절대 제약으로 취급하지 않고 아래 교환관계를 실제로 비교했다.

## 실험과 판단

2026-09-07 12:06 KST 스냅샷 38곳을 사용했다. 현재 운영 설정 기준 예측을 재현한 뒤
새로운 후보 13개(현재 포함 14개)를 비교했다. 운영 설정·입지 점수 원본은 변경하지 않았다.

| 지표 | 현재 | A4 재검토 후보 | 중간 후보 |
|---|---:|---:|---:|
| ±10% | 50.00% (19) | 60.53% (23) | 57.89% (22) |
| MAPE | 10.85% | 10.42% | 10.62% |
| ±20% | 89.47% (34) | 86.84% (33) | 86.84% (33) |
| 최악 과소 | -25.69% | -27.57% | -26.34% |
| 최악 과대 | +27.28% | +21.73% | +23.51% |
| 오차가 큰 20%(8곳)의 평균 절대오차 | 21.67% | 20.98% | 20.90% |
| +20% 초과 과대예측 | 2곳 | 2곳 | 2곳 |

A4 재검토 후보는 lambda 30, 가시성 하한 0.05, 회귀 비중 1이며 실제 매출을 그대로
학습 목표로 삼고 최종 단계에서 유입 제한을 반영한다. 현재 모델은 유입 차감 전 매출로
학습 목표를 환산한다. 중간 후보는 환산 강도를 0.5로 둔다.
따라서 raw 후보는 과소예측 쪽으로 이동하는 효과가 있으며,
목표 정합성이 자동으로 더 좋아진다고 해석하지 않는다.

실매출에서 학습한 공통 가시성 잔차 보정 2개도 비교했다. 제외 점포 매출을 쓰지 않고
학습점포만으로 가시성-매출 관계를 보정했지만, 두 안 모두 ±10% 50%로 개선되지 않았다.
개별 점포의 점수를 실매출에 맞춰 바꾸는 작업은 수행하지 않았다.

## 탐색용 검증 기준

실행 전에 이번 비교 기준을 코드로 고정했다. 아래 허용폭은 사업비용으로 확정한 값이
아니라 교환관계를 드러내기 위한 작업 가정이다.

- ±10% 적중 최소 2곳 증가 및 MAPE 감소.
- ±20% 적중 최대 1곳 감소 허용.
- 최악 과소·과대는 각각 최대 5%p 악화 허용.
- 큰 오차 20%의 평균은 최대 2%p 악화 허용.
- +20% 초과 과대예측 최대 1곳 증가 허용.
- 통과 후보 중 ±10% 적중 우선, 동률이면 MAPE 순으로 선택.

중간 후보 4개는 첫 결과 이후 세운 추가 가설이다. 후보·점수·정책을 모두 과거부터
완전히 사전 고정한 전향적 검증이라고 주장하지 않는다.

## 재검증

타깃 점포를 제외한 내부 LOOCV로 후보를 선택하고 타깃을 예측하는 중첩 검증:
±10% 60.53%, MAPE 10.22%, ±20% 86.84%.
이는 점포마다 내부에서 선택한 모델이 다른 선택 절차의 결과이며,
단일 A4 후보의 MAPE 10.42%를 대체하는 숫자가 아니다.
기존 38곳으로 피처·계수 하한·유입 보정 등을 이미 여러 번 정했으므로
신규점포 독립 성능을 증명하지 않는다.

28곳 부분표본 300회, seed 20260908, 각 표본 안에서 LOOCV 재학습:

| 엄격한 개선 횟수 | A4 | 중간 후보 |
|---|---:|---:|
| MAPE | 260/300 | 227/300 |
| ±10% | 196/300 | 184/300 |
| ±20% | 105/300 | 73/300 |
| 최악 과소 | 0/300 | 36/300 |
| 최악 과대 | 292/300 | 261/300 |
| 큰 오차 20% 평균 | 241/300 | 255/300 |
| 탐색용 기준 동시 통과 | 119/300 | 80/300 |

나머지 회차는 동률 또는 악화이며 개선 횟수의 보수가 곧 악화 횟수는 아니다.
부분표본은 중복되는 같은 점포를 사용하므로 300개의 독립 실험이나 확률 추정이 아니다.

과대예측 오차에 1.5배 비용을 두는 가상 비교에서는 평균 가중백분율손실이
현재 13.78% → A4 12.47% → 중간 후보 13.08%였다.
비용비율은 사용자 사업비용에서 추정한 값이 아니며 실제 금전손실 예측이 아니다.

## Claude 검토 완료와 독립 재계산

Claude CLI가 읽기 전용 검토를 완료했다. 최초 요청은 샌드박스 연결 거부로 실패했고,
승인된 외부 연결에서 재실행해 결과를 받았다. Claude의 파일 수정·배포·운영 쓰기는 없다.

핵심 지적은 적중률 개선에 낮은 방향으로의 편향 이동이 섞였다는 점이다.
직접 재계산한 결과, 현재 오차에 두 모델의 평균편향 차이인 -3.0602%p를 일괄 더해도
±10% 23/38, ±20% 33/38이 재현됐다. 이때 MAPE는 10.99%로 악화한다.
이 상수는 전체 실매출을 보고 만든 사후 진단값이며 배포 가능한 보정계수가 아니다.
따라서 적중 개수만으로 모델 개선을 입증할 수 없지만, 이 계산만으로 A4의 이득 전부가
편향 이동 때문이라고 인과적으로 단정할 수도 없다. A4의 실제 MAPE 10.42%와는 구분한다.

중첩 선택 38회 중 A4 34회, L10/F.05/Nhalf 3회, L10/F.05/Nfalse 1회였음을 재확인했다.

Claude 의견 중 그대로 채택하지 않는 주장:

- 부분표본 기준 통과율 39.7%를 신규점포 성능의 상한으로 해석할 근거는 없다.
- 유입 정규화 0/0.5/1을 곧바로 보정 효과 2/1.5/1회라고 부르는 것은
  표본 간 학습·회귀계수 변화까지 포함한 정확한 수학적 설명이 아니다.
  학습 목표와 최종 보정의 역할이 달라지는 설계 문제로 다루되 사양 오류로 단정하지 않는다.
- 과거 기준 완화를 거부했다는 문서는 이후 사용자가 합리적 변경 검토를 허용한 지시로 갱신됐다.
  기준 재검토 자체를 무권한으로 취급하지 않는다.

판단: 공유 선형 잔차 보정은 효과가 없어 종료한다. A4와 중간안은 비교 후보로 보존하되
운영 대체는 수행하지 않았다. 후속 실험에서는 편향·큰 오차의 크기를 함께 평가하며,
가시성 등급의 비선형 공통 효과처럼 신규 후보지에서도 계산 가능한 점수 함수를 검토한다.
