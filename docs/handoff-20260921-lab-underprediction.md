## 3. 할 일 — 경쟁상권 과소예측을 판다

### ⭐ 제일 유망: 바깥선택지(outsideOptionIp)

`_textbookFull.test.ts`의 [손잡이 훑기]에서 **유일하게 격차와 MAPE를 같이 개선한다**:

```
                     독점     경쟁상권    격차      MAPE
지금 (바깥선택지 0)    3.0%    −12.6%   −15.6%p   22.51%
바깥선택지 50         3.2%     −1.0%    −4.3%p   22.18%   <- 유일하게 둘 다 좋아진다
바깥선택지 100        3.2%     +7.9%    +4.7%p   25.04%
```

뜻: *"경쟁점 말고도 갈 곳이 있다"*(집, 모바일, 다른 여가)를 점유율 분모에 상수로 더하는 것이다.
경쟁점이 없는 독점 상권에서도 우리가 100%를 못 먹는 이유를 설명한다.

**해야 할 일:**
1. 50 근처를 촘촘히 훑는다(25·40·50·60·75). 지금은 0/50/100 셋만 봤다.
2. ⚠️ **무작위 대조군을 반드시 돌린다.** 자유도 1개짜리라 관문이 가볍지 않다.
3. ⚠️ **LOO 벌어짐**을 본다(표본 안에서 고른 값이 홀드아웃에서 유지되나).
4. 값을 고르면 **사용자에게 보고하고 확인받는다.** 이건 [감각] 계수다 — 자료가 방향은
   지지해도 값을 확정해주지 못할 가능성이 높다.

### 다른 갈래 (해봤고 안 된 것 — 되풀이하지 말 것)

같은 [손잡이 훑기]에 이미 있다:
- `θ`(품질 지수) 3→4: 격차는 +0.9%p로 잡히는데 **MAPE가 25.93%로 나빠진다**
- 유효거리 300m→200m: 격차 −4.1%p인데 MAPE 26.04%로 나빠진다
- 자료 없는 경쟁점을 평균/제외로 바꾸기: **MAPE가 한 톨도 안 움직인다**(기존점 0곳이라 대상이 없다)
- 자를 맞춘 뒤 θ 올리기: 22.64% → 27.08%, 나빠진다

### 관문은 통과했는데 아직 본체에 안 들어간 것 (별건)

**잔차화 중심도 ν=0.5** — 중심도에서 유동인구 몫을 걷어낸 값이다.
MAPE 28.58% → **21.59%**, 무작위 대조군 200회 **p=0.005 통과**, LOO 홀드아웃 21.54%로
벌어짐 −0.05%p, 훈련겹 38회 중 37회가 같은 값을 골랐다.

⚠️ **하네스(`_textbookFull.test.ts`)에만 있고 `textbookModel.ts`에는 없다**(확인함).
채택 기준을 전부 통과한 상태라 옮기기만 하면 되는데, **새로 고를 계수가 없다는 점에서
제일 안전한 건**이다. 과소예측 작업 전에 이걸 먼저 넣어 기준선을 올려도 된다.
