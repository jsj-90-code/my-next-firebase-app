## 1. ✅ 오늘 채택한 것 둘

### (1) 잔차화 중심도 ν=0.5 — 오전

중심도 날값에 **동네 규모가 섞여 있어**(유동400m와 r=0.599) 수요식과 이중계산이었다.
회귀 잔차만 쓰니 겹침이 **−0.154**로 사라진다.

정직한 홀드아웃(축척·기울기 **둘 다** 훈련겹에서만): 손 안 댄 ν=0.25 **24.40%** →
잔차화 ν=0.5 **22.12%**. 겹마다 기울기를 재적합해도 유지된다.

⚠️ 인계 문서에 *"새로 고를 계수가 없다"*고 적혀 있었는데 **틀렸다.** 굳힌 상수가 셋
(기울기 0.4801 · G_c 3.2719 · G_f 75093)이고 ν도 바뀐다. **표본이 늘면 다시 적합할 것.**

### (2) 산업단지·기타 배수 1.00 — 오후

수요 축척은 독점 3곳에서 맞추는데 그 3곳이 **탕정역(산업단지)·남악(기타)·광주각화(없음)**
이었다. 즉 두 유형이 **자기를 재는 자를 부풀리고** 있었다.

자를 바로잡고 다시 뽑으니 군부대 2.22 · 대학가 1.45는 **그대로**, 산업단지 1.08 ·
기타 0.94는 **사실상 1**. 그래서 둘을 껐다.

📌 끄니까 기준점 3곳이 자동으로 전부 1.00이 되어 **예외 규칙 없이 순환이 끊긴다.**
기준점 벌어짐 1.416 → **1.019배**.

⚠️ **성적으로 고른 게 아니다** — 표본 안 MAPE는 오히려 나빠지고 LOO는 같다.

## 3. 할 일 — 대학가 3곳 과대예측

배수를 고친 뒤 오차 구성이 바뀌었다. **수요부족 4곳 → 2곳**으로 줄었는데, 대신
**대학가가 과대예측으로 밀렸다.**

```
[20% 넘는 16곳]  수요부족 2곳 · 경쟁 과대 8곳 · 경쟁 과소 6곳

  부경대점     +69.7%   필요 18% · 예측 28%   ← 대학가. 최악
  전대상대점    +41.7%   필요 33% · 예측 42%   ← 대학가
  전대후문점    +40.2%   필요 60% · 예측 77%   ← 대학가
  광주첨단점    −54.6%   필요 39% · 예측 19%
  진주혁신도시본점 −52.9%   필요 65% · 예측 32%
  문경시청점    −51.8%   필요 191%             ← 수요부족(점유율로 못 고침)
  양주덕정점    −50.9%   필요 121%             ← 수요부족
```

### ⭐ 제일 유망: 대학가 배수 1.45를 다시 본다

부경대는 주거 9,433명으로 표본 최대급인데 **배수 1.45까지 받아** 수요가 과하다
(필요 점유율 18% = 동네 수요의 18%만 먹어도 실매출이 나온다는 뜻).

**해야 할 일:**
1. 대학가 5곳을 개별로 열어라 — 중앙값 1.45가 맞아도 개별 매장이 틀릴 수 있다.
2. ⚠️ **재도출 비(1.45)는 축척과 무관하다**(유형 간 비율이라 A가 바뀌어도 그대로).
   그러니 "자가 바뀌었으니 1.45도 다시 뽑자"는 안 통한다. 이미 확인했다.
3. 대학가 안에서 **무엇이 부경대를 다르게 만드는가**를 봐라(재학생 수? 기숙사? 인구 규모?).
4. ⚠️ 사용자 지적 — *"같은 군부대라도 규모가 다를 수 있다."* 곱셈이 아니라 **덧셈**
   (실제 재학생·병력·종사자 수를 수요에 더하기)이 물리적으로 맞다. 자료가 필요하다.

### 다른 갈래

- **경쟁 과대 8곳** — 경쟁무게 0.38배가 필요한데 **가르는 변수가 없다**(22개 훑었음).
  전체를 띄우는 상수(바깥선택지·θ)가 하는 일이라, **값 결정 문제**다.
- **문경(191%)·양주덕정(121%)** — 수요부족 2곳. 점유율로는 못 고친다. 5km 상권 가설이
  남아 있다(`scripts/collectSgisResidentPopulation.mjs`의 `RADII`에 5000 추가).

## 6. ⚠️ 오늘 밟은 함정 셋 — 같은 걸 또 밟지 말 것

1. **나눗셈 함정** — *"인구 적은 동네를 작게 센다"*(r=−0.696)고 봤는데 **자동으로 나는
   값**이었다. 필요 점유율은 수요(∝인구)로 나눈 값이다. 과녁은 **필요÷예측**을 써라
   (r=−0.162, 편향 없음).
2. **대조군 기준선** — 섞으면 기준선도 바뀌어서 '이득 폭'을 나란히 못 놓는다.
   **기준선 두 줄을 같이 찍어라.** 바깥선택지에서 p가 0.965 → 0.682로, 거리 감쇠에서
   0.781 → 0.139로 바뀌었다.
3. **이중 잔차화** — 잔차화를 본체에 넣은 뒤 하네스가 또 하면 숫자가 망가진다.
   `_textbookFull`은 아침에 고쳤는데 `_residualCentralityPort`를 놓쳐서 저녁에 잡았다.
   **본체에 무언가를 채택하면 그걸 손으로 하던 하네스를 전부 찾아라.**

곁다리로 **`_textbookFull`의 LOO 버그**도 고쳤다 — `scoreTextbook`은 rows를 오차
내림차순으로 정렬해 돌려주는데 홀드아웃 매장을 `sc.rows[i]`로 집고 있었다. 문서에 적혀
있던 "LOO 벌어짐 −0.05%p"가 그 값이다(고치니 +0.85%p).
