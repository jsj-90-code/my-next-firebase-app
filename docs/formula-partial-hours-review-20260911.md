# 예상 이용시간 연동안 B의 정보량 검토

## 확인된 구조

고정 코드 1477c23, 2026-09-09 보존자료 38곳에서, ridge 100%·baseline 0%인 현행 로그선형 모형을 대상으로 한다. X는 요금을 제외한 현행 특징 벡터, P는 시간요금, N은 PC 수다.

```
log(H예측/N) = a0 + aP*log(P) + aX·X
F예측 = N*exp(g(X)) * ((H예측/N)/Href)^alpha
log(F예측/N) = g(X) + alpha*aX·X + alpha*aP*log(P)
               + alpha*(a0-log(Href))
```

g도 같은 X의 선형식이면, 연동안이 추론 시 추가하는 선형 변수는 log(P)이고 나머지는 기존 계수의 결합이다. Href가 고정 양수이면 절편만 바꾼다. 실제 측정 이용시간·고객수·구매율이라는 새 관측정보가 들어오는 것은 아니다.

재현 스크립트 `.local-tools/partial-hours-identity-20260911.cjs`는 기존 예측 함수에서 얻은 시간·상품매출을 직접 곱한 값과 위 전개식을 비교했다. 38곳 최대 상대오차 2.34e-15 미만으로 일치했다. 재적합 및 정확도 검증이 아닌 수식 항등 확인이다.

현행 시간모형의 요금 원단위 계수는 -0.61475444다. alpha=0.5이면 상품매출에 -0.30737722의 요금 계수를 암묵적으로 넣는다. 다른 입력과 모형을 고정할 때 요금 10% 증가에 상품매출 약 2.887% 감소가 붙는다. 이는 관측된 가격 인과효과가 아니라 해당 후보가 부여하는 예측 반응이다.

## 검증 설계에 미치는 영향

- B를 새 수요정보의 추가라고 설명하지 않는다. 구조적 가정·계수 결합·규제 효과를 검증하는 후보로 분류한다.
- 학습에는 해당 점포를 제외한 OOF 시간 예측을 사용해야 한다. OOF 모델마다 계수가 달라지므로 학습 데이터까지 완전한 선형 중복이라고 단정하지 않는다.
- 상품모형에 요금만 넣는 `tariffFeature=both`를 대조군으로 고려한다. B의 개선이 단순 요금 추가를 넘는지 확인하는 목적이다. 기존 2026-09-10 검증에서는 usage-only 10.129%, both 10.337%였지만, 월수 가중치 등 조건이 다른 과거 결과이므로 현재 B의 실패를 증명하지 않는다.
- 계수 하한과 ridge 벌점이 있어 수식의 표현력이 같더라도 재학습한 최종 모형은 같지 않을 수 있다. B를 무의미하다고 폐기하거나, 반대로 유일한 개선 경로라고 표현할 근거는 없다.
- 위 항등식은 혼합 baseline, 시간 상한을 통한 비선형 연동, overflow 또는 별도 추가 변수를 넣으면 그대로 적용할 수 없다. 현재 진단은 이들을 포함하지 않는다.

## 이용률 원자료 조사 상태

[한국콘텐츠진흥원 2025 게임이용자 실태조사](https://welcon.kocca.kr/ko/info/report/1956850)의 공식 PDF를 내려받아 474페이지의 텍스트를 추출했다. 조사항목표 PDF 29~30쪽은 PC게임 이용을 다룬다. PC게임과 PC방은 동일한 모집단·행동이 아니므로 플랫폼 이용률을 현재 PC방 연령별 이용률에 대입할 수 없다. PDF 240쪽 설문에는 PC게임 비용에서 PC방 이용료를 제외하는 설명도 있다. 텍스트 검색만으로 PC방 관련 표의 완전한 부재를 단정하지 않으며, 현재 고정 연령·성별 PC방 이용률의 직접 출처는 아직 확인하지 못했다.

기존 이용률을 공식 조사로 검증 완료했다고 표기하지 않는다. 다음 자료를 확보하면 적용 가능성을 판단한다: 전체 주민 대비 PC방 방문확률, 방문자당 동일 기간 방문횟수, 방문당 체류시간, 조사 연령·지역·기간. 방문자만의 이용빈도에 전체 주민수를 바로 곱하거나, PC게임 이용률을 PC방 방문확률로 바꾸지 않는다.

## 수요 총량의 일괄 보정은 재학습 후 사라질 수 있다

`.local-tools/demand-scale-identity-20260911.cjs`에서 모든 학습점과 예측점의 marketDemand를 각각 0.5배·1.1배·2배로 바꾸고 동일 절차로 재적합했다. PC시간 및 상품매출의 원시 예측 최대 상대차는 세 경우 모두 1.78e-15 미만이었다.

이는 `log(k*D/(N+C))=log(D/(N+C))+log(k)`이고, 학습 평균도 log(k)만큼 이동하여 표준화 특징이 같아지기 때문이다. 따라서 전체 이용률이나 방문빈도에 같은 배율을 곱하는 것만으로는 이 경로의 정확도를 높일 수 없다. 고정된 모델에 수요만 늘리는 민감도 실험과, 학습자료에도 동일 변경을 적용하는 정책 변경은 구별해야 한다.

검증 범위는 직접 marketDemand를 반올림 없이 일괄 변환한 순수 ridge 모형이다. `D/(N+C)`의 로그 입력 하한 0.1에 걸리지 않는 범위여야 한다. 시장유형 선택, 점수격차, overflow, 수용한도 또는 다른 경로까지 바뀌는 운영 변경 전체의 불변성을 주장하지 않는다. 연령별 이용률을 서로 다른 비율로 바꾸면 지역 간 상대수요가 달라져 이 항등성이 적용되지 않는다.

적중률 개선을 위한 원자료 조사에서는 전국 평균 배율보다 **점포 간 수요 차이를 설명하는 정보**를 우선한다. 예를 들면 측정 정의를 맞춘 연령별 방문빈도·체류시간, 시간대별 유동과 영업시간의 겹침, 실제 접근 가능한 경쟁좌석이다. 이 항목들은 확보·검증할 후보이며 현재 자료로 효과가 확인된 추가 계수는 아니다.

## 추가 변수의 측정 시점: 경쟁점 가동률은 과거 예측에 그대로 넣지 않는다

`.local-tools/target-vintage-audit-20260911.json`에 기존 함수와 같은 매출 선택 조건을 재구성하고, 점포별 월수가 학습자료와 일치하는지 확인했다. 매출 평가기간이 2025년 전에 끝나는 곳은 11/38, 2026년 전에 끝나는 곳은 24/38이다. 모두 2024년 인구자료를 쓰며, 11곳은 개점연도가 2023년이다. 자료의 DB 수정일은 원자료 관측일·공개일과 같다고 취급하지 않았다.

연결된 경쟁점 중 `pingbotPeriod` 날짜가 명시된 문서는 35건이다. 그중 21건(자사 17곳에 연결)은 관측 종료월이 해당 자사 매출 평가기간의 마지막 월보다 뒤다. 기간 문자열의 명시 날짜만 비교했고, 종료월이 같은 자료도 개점 전에 확보 가능했다는 뜻은 아니다.

이는 현재 산식의 가동률 누수를 발견했다는 뜻은 아니다. **추가 후보로 가동률을 넣을 때의 시점 부적합**을 확인한 것이다. 2026년 경쟁점 가동률로 2023~2025년 매출을 설명한 성능을 과거 개점 전 예측력이라고 보고할 수 없다. 이미 영업 중인 자사점이 경쟁점 가동률에 영향을 줄 가능성도 있으므로, 개점 전 정보인지 함께 확인한다.

적용 설계는 다음과 같다.

1. 입력마다 `observedFrom`, `observedTo`, `availableAt`, 출처, 단위, 누락 여부를 기록한다. 실제 기록이 없으면 추정 날짜로 채우지 않는다.
2. 개점 전 매출예측 검증은 예측 기준일 이전에 확보 가능했던 자료만 사용한다. 현재 상태 진단용 자료와 목적을 구분한다.
3. 시점이 맞지 않는 가동률은 현황 참고로 보존하고, 기존 38곳에 대한 신규 변수 채택 근거로 사용하지 않는다. 향후 후보지에서 개점 전 관측을 고정 저장하고 완료월 실적이 생긴 뒤 평가한다.
4. 월 매출 평가기간·요금 기준기간·좌석 기준기간도 함께 고정한다. 현재 요금으로 과거 매출을 나눈 값은 실제 이용시간이 아니라 대용치라는 표시를 유지한다.

이 절차는 계수를 하나 더 넣는 것보다 검증 수치와 실제 신규 점포 적중률의 차이를 줄이는 데 필요한 설계다. 얼마나 개선되는지는 아직 측정하지 않았다.
