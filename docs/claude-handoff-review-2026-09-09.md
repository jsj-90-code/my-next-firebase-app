## 전달 내용의 적용 판단

1. A4 채택 가능이라는 과거 결론은 현재 분리 모형에 적용하지 않는다. `_a4Rework.test.ts`는 저장된 파생 점수와 직접 구성한 총매출 회귀를 사용한다. 현재 원본 입력 재계산, 외부유입 차감 전 목표 학습, PC·먹거리 분리 모형과 다르다.
2. 요금 계수를 억지로 높이지 말고 이용량과 요금을 분리하자는 방향은 현재 구현에 반영돼 있다. 과거 탄력성 숫자는 현재 모형의 성능이나 가격 변경에 대한 고객 반응을 입증하지 않는다.
3. 점포 간 요금·대당매출의 상관이나 구간 비교만으로 가격 인상에 따른 가동률 하락을 확정할 수 없다. 또한 PC매출이 요금에 정비례하고 먹거리가 고정이면 총매출의 비례 변화는 PC매출 비중에 따라 달라진다.
4. 계수가 하한에 붙었다는 사실만으로 하한이 없을 때 계수가 정확히 0이라고 말할 수 없다. 실제 구현은 계산된 계수가 하한보다 작으면 하한으로 올린다.
5. 현재 학습의 과거 PC매출 / 현재 등록요금은 이용시간 대용값이다. 당시 실효요금이나 실제 유료 이용시간은 확인되지 않았다. 요금 직접 반영은 사용자가 선택한 구조이며 실제 수요반응의 실증 결과가 아니다.
