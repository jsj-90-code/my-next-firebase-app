## 결과 확인 전 고정한 비교 조건

보존자료 2026-09-09, 고정 코드 1477c23, 기존 정식 38개 점포를 사용한다. 비교안은 아래 세 개이며 결과에 맞춰 지수·가중치·하한을 탐색하지 않는다.

1. 기준: 기존 `log(D/(N+C))`와 `Qown*log(gap)` 유지.
2. 대조: 기존 수요 특징을 유지하고 격차 특징과 대응 계수 하한을 제거.
3. 통합: 수요 특징을 `log(max(0.1, D/(N+C/gap)))`으로 바꾸고 격차 특징과 대응 계수 하한을 제거.

양수 점수와 대수의 집계 범위가 같으면 `C/gap = Σ(n_j*q_j)/Qown`이다. 점수는 서열 척도이므로 이 비율이 실제 경쟁흡인력에 비례한다는 것은 검증할 가정이다. 거리 가중이나 새로운 계수는 추가하지 않는다. 나머지 특징, 표준화, ridge, 월수 가중 k=2.46 및 내부 교차보정을 유지한다.

외부 LOOCV마다 평가점포를 제외하고 학습하며 교차보정은 남은 훈련집합 안에서만 계산한다. 다만 k와 기존 설정은 과거 전체자료에서 정해진 값이므로 완전한 독립 검증이 아니다. 이미 탐색에 사용한 표본의 비교로 보고한다.

총매출 MAPE, ±10%·±20% 점포 수, 최악 오차와 개별 오차 변화를 함께 기록한다. 기존 인계 기준인 ±10% 증가 및 ±20% 비악화를 충족하는지도 확인하되, 충족만으로 운영 채택이나 신규점 성능을 확정하지 않는다.

방향 검증은 각 모형의 전체표본 학습을 고정하고 경쟁점 하나씩 좌석 +1대, +60대, 경쟁점 전체 제거를 비교한다. 대수·점수 집계 일치를 먼저 확인하며, 가상 변화에서 점수·총수요·자사좌석·요금은 고정한다. 초과수요는 0으로 두고 기존 이용시간 상한은 유지한다. 이는 좌석 재구성으로 개별 점수까지 달라지는 경우나 전체 후보지 경로의 검증이 아니다.

## 방향 보장과 정확도는 별개

`x = log(D/(N+Σ(n_j*q_j)/Qown))`이면, 로그 하한이 작동하지 않고 다른 입력이 고정된 구간에서

```
dx/dn_j = -(q_j/Qown) / (N+Σ(n_j*q_j)/Qown) < 0
```

양수 경쟁점수가 고정되고 수요 특징의 회귀계수가 비음수라면 시간·상품 예측 모두 비증가한다. 로그 하한, 이용시간 상한, 반올림은 평탄 구간을 만들 수 있으므로 일반적으로 엄격 감소를 보장하지 않는다. 현재 실험의 초과수요는 0이다. 점수 재산정·수요 변화·거리 가중·초과수요 재배분이 같이 움직이는 전체 경로에는 이 증명을 그대로 적용할 수 없다.

기존 격차 항이 가진 예측 신호를 단일 분모로 바꾸면 자유도와 함수 모양, 표준화 후 하한의 원단위 효과까지 달라진다. 이번 비교는 이를 묶은 설계 변경의 결과이며, 악화 원인을 한 가지로 분리해 증명한 실험은 아니다. 경쟁이 늘어 매출이 오르는 방향 문제를 해결했다는 사실만으로 적중률 개선을 주장하면 안 된다.
