## 1. 외부옵션 20대를 뺐다

점 3개에 맞춘 값이었고 정체가 **반경 밖 경쟁점**이었다. 빼니 편향 +3.28%p가 드러났고,
그게 곧 "2km를 안 셌다"는 표시였다. **2km를 넣으니 그 자리가 채워졌다(−0.63%p).**
상수 하나로는 못 할 일이다 — 상수는 전 매장을 똑같이 누르는데 경쟁점은 매장마다 다르게 깎는다.

### ⚠️ 아침 인계문의 숫자 둘이 재현 안 됐다
- "빼면 점유율 잘림이 **기존점** 5곳(호구포역·영월)" → 그 둘은 **후보지**다. 기존점은 3곳이었다
- "±5%p 19/40 · 편향 −0.43%p" → 내 경로에선 16/40 · +0.09%p. MAE는 6.43 vs 6.44%p로 맞다
**인계문 숫자를 인용하기 전에 한 번 재라.**

## 2. ⭐ 2km 경쟁점 — 채택했다

```
실체 = 카카오 장소(격자수집) − 오락실·성인PC방 상호
시점 = 공공데이터 인허가 개업일·폐업일 → 평가창 12달 중 영업한 달의 비중
대수 = 500m 안 미조사 경쟁점과 같은 기본대수
```

| | 전 | 후 |
|---|---|---|
| MAE | 7.72%p | **6.26%p** |
| SD | 9.02%p | 7.92%p |
| 최악 | 24.07%p | **17.68%p** |
| 편향 | +3.28%p | **−0.63%p** |
| ±5%p | 15/40 | **19/40** |
| 퍼짐 | 1.76배 | 1.46배 |
| 점유율 100% 잘림 | 3곳 | **0곳** |

편향 검정(유의선 ±0.41)과 민감도를 다 통과했고 **고른 계수가 없다.**

### 2-1. ⚠️⚠️ 실체 판정의 순위 — 이걸 틀리면 전부 틀린다

```
카카오  >  소상공인 상가업소  >  인허가
```

**상가업소도 인허가도 폐업을 못 따라온다.** 사용자가 구리돌다리에서 확인해 줬다 —
자동 목록이 낸 10곳 중 7곳이 *"네이버지도에 안 떠, 폐업으로 추측됨"*이고 **카카오에도
하나도 없다.** 사용자가 꼽은 4곳(불독·녹스·지원·레드포스)은 **카카오에 전부 있다.**
500m 채점에서도 카카오는 사람이 조사한 실재 273건 중 **270건(99%)**을 맞혔다.

> **나는 오늘 카카오 판단을 세 번 틀렸다.** (1) 아침에 "도시 편향"으로 기각 — 눈대중이었고
> 재 보니 r=−0.14로 유의선 아래. (2) 상가업소로 갈아탐 — 사용자 확인으로 뒤집힘.
> (3) 40건 상한을 "편향의 원인"으로 지목 — 풀어 보니 성적이 안 바뀜.
> **자료원은 성적이나 인상으로 고르지 말고 아는 답과 대조해라.**

### 2-2. 결합 방향 — 인허가로 목록을 만들지 마라

같은 건물에 PC방 등록이 대여섯 개씩 겹쳐 있어서, 인허가를 기준으로 돌리면 그 안의
진짜 가게 하나가 **죽은 등록을 전부 살려 준다**(안산선부 500m에서 34건 vs 실제 12건 —
상호가 "퍼니PC방(적발:2010.3월경)" "해피데이PC (유선통보 2009.)"다).
**인허가는 이미 확인된 가게에 날짜만 달아 준다.**

### 2-3. 카카오 40건 상한 — 풀었고, 문제가 아니었다

`scripts/collectKakaoPcBangsGrid.mjs`가 **잘리면 그 구역을 넷으로 쪼개 다시 묻는다**.
54지점·질의 153회·끝내 잘린 곳 0곳. 신중동 45→67 · 전대후문 45→55 · 수원인계 45→54 등
다섯 곳이 늘었고 **나머지 49곳은 건수가 정확히 같다**(검산이 됐다).

⚠️ **그런데 성적이 안 바뀐다**(6.26 → 6.26%p). 카카오는 **가까운 순**으로 주니 잘린 건
전부 먼 것들인데, 거리 감쇠가 1km에서 0.018배라 90대가 0.14대로 들어간다. 사실상 0이다.
→ 대신 **자료가 조금 빠져도 결과가 안 흔들린다**는 확인이 됐다.

⚠️ 격자로 받으면 카카오가 주는 `distance`가 **물어본 지점 기준**이라 못 쓴다.
매장 중심에서 다시 재야 한다. 놓치면 거리 감쇠가 통째로 틀어진다.

## 3. ⛔ 유일하게 막힌 자리 — 경쟁점 PC 대수

**또 파기 전에 여기를 읽어라. 오늘 다 해 봤다.**

| 시도 | 결과 |
|---|---|
| 우리 매장으로 면적→대수 회귀 | **R²=0.064.** 전부 90~110대 규격형이라 대수 방향으로 안 퍼져 있다 |
| 조사 경쟁점 138곳으로 회귀 | 대수=0.2213×면적+41.7 · R²=0.679인데 표본이 **61~243대**뿐이라 소형 구간이 외삽 |
| 인허가 시설면적 | **40%가 말이 안 된다**(우리 발산역점이 95대에 25.04㎡) |
| 인허가 총게임기수 | 70+ 는 실측과 일치(±20% 안 78%)인데 **지역 편향 r=−0.486**(서울 53% 미등록 vs 울산 4%) |
| 총게임기수 작은 값 | **가짜다.** 사용자: *"20대, 6대 매장 없어 저거 가짜야"* |
| 면적 문턱으로 대형만 세기 | 우리 500m DB 재현 F=0.66이 최선. 게다가 **빼면 성적이 나빠진다** |

**=> "기전이 없어서"가 아니라 "기전은 있는데 자료가 계수를 못 고른다"이다.**
새 자료(소형 PC방 대수)가 들어오면 열리는 갈래다. 산식부터 손대지 마라.

## 4. 원장으로 오차를 쪼갰다 — 범인은 이용자 수다

가동률 = (이용자 수 × 1인당 시간) ÷ (PC×720)이고 **원장에 둘 다 있다.** 관문 8/8 통과.

| | 이용자(예측÷실측) | 1인당시간(산식÷실측) |
|---|---|---|
| 1년 안 4곳 | 1.211배 (퍼짐 0.207) | **1.006배** (퍼짐 0.111) |
| 1년 초과 4곳 | 1.209배 (퍼짐 0.348) | 0.711배 (퍼짐 0.099) |

1. **이용자 수의 퍼짐이 1인당 시간의 2~3배다.** 범인은 이용자 수다
   → 아침 인계문 3번 과제("1인당 시간을 매장별로")의 답: **할 필요 없다**
2. 오픈 1년 안에서 시간 어긋남이 **1.006배** — 축척 8.20h가 맞다는 독립 재확인
3. 이용자 수 1.21배 과대가 **경쟁 없는 3곳의 1.207배와 같다** → 경쟁 항과 무관하게 얹혀
   있었고, 그게 2km로 설명된다(편향 +3.28 → −0.63%p)

⚠️ 원장 8곳에 **경쟁점 없는 매장이 하나도 없어** 수요층만 따로 볼 자리가 없다.
독점 3곳(탕정역·광주각화·남악) 원장을 받으면 그 자리가 생긴다.
