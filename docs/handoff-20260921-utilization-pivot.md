그리고 실제로 판이 뒤집혔다:

```

계단300         6.06%p   4.58%p   52.4%
```

옛값을 양쪽에서 이기는 칸 11개 중 **최악 손해가 제일 작은**(+0.7%p) 칸을 골랐다.
⚠️ 자료는 후보들을 못 가른다(95% 구간이 0을 품는다). 관례대로 실무 판단으로 골랐다.
⚠️ **감쇠는 어떤 값으로도 계단300보다 평균·폭을 동시에 개선하지 못한다**(42칸 전부).

같은 커밋에서 **화면이 거짓말하던 것**도 고쳤다 — 실험실 경쟁점 인식표가 감쇠 채택 뒤에도

본체에 내보내 산식과 화면이 같은 식을 쓰게 했다.

## 3. ⭐⭐ 산식 재정립 — 1~4단계 결과

사용자: *"가동률 기준으로 산식 재정립하자. 처음부터 다시 검토해보자."*

### 1단계 — 퍼짐의 95%가 수요 추정에서 온다

```
D = log(총수요시간) − log(자사PC x 720)
  log 총수요시간   Var 0.1879   D분산의 95%
  log 자사PC       Var 0.0146   D분산의  7%   (76~130대, 거의 안 변한다)
```

D는 실측보다 **2.34배 넓다**(±56% vs ±21%).
⚠️ 단, 수요 1→4분위에서 **경쟁IP도 3.6배 는다.** "수요 무관"으로 읽으면 틀린다.

### 2단계 — 자료가 **지수 1을 거부한다**

산식은 `가동률 = (수요÷총공급)^1 × 입지^1`인데, 자료가 원하는 건:

```
b = 0.304 · c = 0.135   (R² 0.285)
38겹 재적합 분포: b 0.264~0.349(SD 0.015) · c 0.076~0.191
→ 1을 전혀 안 품는다. 겹마다 흔들리지도 않는다.
```

**c(입지)가 제일 큰 과장원이다** — b만 풀면 6.08%p, c까지 풀면 4.34%p.

| 모형 | MAE | SD | 최악 | ±5%p |
|---|---|---|---|---|
| 전부 훈련평균 | 4.38%p | 3.92%p | 80.2% | 26/38 |
| **지금 산식** | **6.50%p** | 4.08%p | **49.0%** | 17/38 |
| b·c 자유 | 4.34%p | 2.95%p | 65.1% | 26/38 |
| b=0.3·c=0.15 | **4.03%p** | **2.82%p** | 61.8% | **27/38** |

⚠️ **두 가지를 같이 봐야 한다** — 최악이 49 → 62%로 나빠지고,
'전부 훈련평균'을 **유의하게 못 이긴다**(95% [−1.07, +0.42]).

### 3단계 — 잔차를 설명하는 변수가 **없다**

11개를 훑어 **±0.41을 넘는 게 하나도 없다.**

⭐ 특히 **시급이 아무 일도 안 한다.** 지금 산식은 시급을 단가층에만 쓰고 가동률엔 안 쓰는데,
넣어도 안 좋아진다(r=−0.07, 대조군 p=0.440). 1,000~1,800원 1.8배 차이인데 사분위
가동률이 30.9 / 32.3 / 34.1 / 32.6%로 평평하다.

🟡 무작위 대조군 200회에서 QSC(p=0.015)·자사경쟁력점수(p=0.035)만 0.05를 넘는데,
11개를 훑었으므로 본페로니 문턱 0.0045에 **둘 다 미달**이다. QSC는 최악이 65→78%로
나빠지고 후보지엔 자료가 없어 예측값을 못 바꾼다(2026-09-20과 같은 결론).

### 4단계 — 실무에 무슨 뜻인가

```
기존점 **실측**        중앙 32.3%  범위 17.6~46.5%  SD 5.7%p
후보지 예측(지금)       중앙 21.0%  범위  7.8~36.5%  SD 8.5%p   <- 2.42배 넓다
후보지 예측(지수 교정)   중앙 29.0%  범위 19.7~34.2%  SD 4.0%p   <- 0.80배
```

**13곳 중 4곳이 기존점 실측 최저(17.6%)보다 낮게** 나온다 —
창원상남 7.8% · 영월 8.6% · 울산삼산 13.5% · 춘천퇴계 16.9%.
**한 번도 관측된 적 없는 구간의 외삽**이고, 이게 그 후보지들이 V62 대비
−59~−75%로 나온 정체다.

⚠️ **"산식이 쓸모없다"로 읽으면 안 된다.** 표본 38곳은 우리가 **골라서 연** 자리다.
나쁜 자리는 애초에 안 열었으니 가동률이 좁게 모인 게 당연하다.
바른 결론: **우리가 연 매장들 사이에서는 변별력이 검증되지 않는다.** 범위 밖은 자료가 없다.

## 7. 다음에 할 일 — **사용자 결정 대기**

재정립이 막다른 곳에 닿았다. 자료가 하는 말은 이렇다:

- 지수 1은 **확실히 틀렸다**(b=0.30·c=0.135, 38겹 전부 1을 거부)
- 그런데 고쳐도 **'전부 평균'을 유의하게 못 이긴다**
- 추가 변수도 **없다**
- 그리고 지수를 고치면 **최악이 49 → 62%로 나빠진다**

갈림길 셋:

1. **지수를 채택한다** — 평균·폭은 좋아지고 최악은 나빠진다. 후보지 예측 폭이
   자료가 지지하는 수준(0.80배)으로 들어온다. ⚠️ 계수 둘 추가.

   화면에 외삽 경고를 띄운다. 계수를 안 늘린다.
3. **표본을 기다린다** — 45~50곳(2027 상반기). 지금 판정은 전부 n=38이다.

⚠️ 어느 쪽이든 **"우리가 연 매장들 사이에서는 변별력이 검증 안 된다"**는 사실은 안 바뀐다.
