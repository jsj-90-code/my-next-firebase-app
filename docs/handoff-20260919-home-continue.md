## 2. ⚠️⚠️ 어제 밟은 함정 둘 — 이게 제일 중요하다

### 함정 1. MAPE 하나만 좋아지는 변경

두 번 걸렸다.

```
  자사 먹거리 4 -> 5   MAPE 22.51% -> 22.02%  (좋아짐)
                       중앙 14.3% -> 16.4%    (나빠짐)
                       ±20%  63%  -> 58%      (나빠짐)

  수요 b=1 -> 0.9      MAPE 22.51% -> 22.30%  (좋아짐)
                       중앙 14.3% -> 15.0%    (나빠짐)
                       LOO 22.53% — 안 하느니만 못함
```

먹거리는 **위쪽도 훑어서** 잡았다. MAPE가 4에서 안 꺾이고 5까지 계속 좋아졌다 —
"MAPE가 4를 골랐다"는 말이 성립하지 않는다는 뜻이다. **한쪽만 훑지 말 것.**

사용자 본인의 말(2026-09-18):
> *"일단 이러면 안 되는데 산식이 얼마 안 남았고 자료 넣을 것도 이제 끝이 보이니까 MAPE 신경 쓰게 되네."*

`textbookModel.ts` 머리말: *"기존 산식과 다른 점은 **회귀로 덮지 않는다**는 것이다."*
정확도만 원했으면 만들 이유가 없다 — 운영 V62가 이미 9.26%다.

### 함정 2. 나눗셈을 상관으로 읽기

```
  필요 점유율 = 실측 가동률 ÷ 산식 수요
                              ↑ 분모에 산식 수요
  -> 필요 점유율 ↔ 산식 수요 순위상관 -0.816
```

**이건 상관이 아니라 나눗셈이다.** 수요를 아무 숫자로 흔들어도 -0.8쯤 나온다. 어제 이걸
"제일 센 신호"라고 읽고 b를 넣었다가 LOO에서 기각됐다.

**예측값이 분모(또는 분자)에 들어간 지표는 자기 자신과 상관이 난다.** 그런 상관은 증거가 아니다.

### 값 바꿀 때 볼 것 셋

```
  1. 세 자가 같이 움직이나        MAPE만 좋아지면 눈금 옮긴 것
  2. 안 본 매장에서도 되나        LOO — 한 곳 빼고 맞춘 뒤 그 곳 맞히기
  3. 아무 데나 붙여도 되나        무작위 대조군 — 섞어서 돌려보기
```

## 3. ⭐ 다음 할 일 — 문경시청점·양주덕정점 두 곳

### 왜 이 둘인가

**필요 점유율이 100%를 넘는다.** 이건 구조적으로 특별하다.

```
  필요 점유율 = 우리 실측 가동률 ÷ (경쟁이 없다고 볼 때의 예측 가동률)
  -> 경쟁점 자료가 한 글자도 안 들어간다. 우리 실측과 산식 수요, 둘뿐이다.

  문경시청점  226.3%   주거 1km 18,786명 (표본 최소) · 유동 400m 27,745 · PC 98대
  양주덕정점  144.2%   주거 1km 28,495명 · 유동 400m 44,214 · PC 119대
  (강릉교동점 108.3% — 경쟁점 실측이 33%뿐이라 셋째로 둔다)
```

100%를 넘는다는 건 **동네 수요를 우리가 전부 다 먹어도 실제 판 것에 못 미친다**는 뜻이다.
경쟁을 어떻게 세든, 품질·입지를 어떻게 보든 못 고친다. **수요식이 이 두 곳을 작게 세고 있다.**

### 어제 기각된 설명 — 다시 하지 말 것

- ❌ "동네가 작아서 정비례가 안 맞는다" → 수요 ∝ 인구^b, LOO가 더 나쁨(10번)
- ❌ "특수수요 배수가 모자라서" → 둘 다 특수수요 `없음`이라 손댈 칸이 없다
- ❌ "경쟁 항이 과해서" → 100% 초과는 경쟁으로 설명 불가

### 그래서 개별로 볼 것

이 둘에 **산식이 못 보는 개별 사정**이 있다. 볼 목록:

1. **반경 밖에서 오는 손님** — 문경시청은 시내에 PC방이 적다. 반경 400m/1km 밖에서도 온다면
   지금 수요식 구조로는 못 잡는다. 확인: 두 곳의 경쟁점 수(문경 3곳 vs 부경대 9곳),
   그리고 인근 PC방 밀도를 다른 매장과 견줄 것.
2. **평가창 실매출·가동률이 맞나** — `utilizationRate`가 이상하게 높은 게 아닌지 원자료 확인.
   문경시청 가동률 30.6%는 주거 1.9만 동네치고 높다.
3. **유동인구 자료가 이 동네에서 맞나** — 소상공인365 유동이 시골에서 과소 집계될 수 있다.
   `.local-tools/sbiz-floating-population.json`에 100~1000m 전 반경이 있으니 단조성 확인.
4. **PC수 대비 매출 구조** — 두 곳 다 PC 98·119대로 표본 평균 근처다. 단가층 확인.

⚠️ **두 곳을 고치려고 전역 계수를 만들지 말 것.** 두 곳 때문에 38곳이 움직이면 그게 어제
   열 번 기각된 그 패턴이다. **먼저 "왜 그런가"를 알아낸 뒤에 그게 다른 매장에도 있는지 본다.**
