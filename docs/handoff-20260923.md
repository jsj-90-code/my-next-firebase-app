## 1. ⛔⭐ 제일 중요한 것 — '전부 평균'에 진다

사용자: *"매장별 편차가 없어서 신뢰가 안 된다. 이거 뭐 그냥 평균 맞추기 한 거 아냐?"*

```
  경우             MAE      최악      ±5%p    예측 퍼짐
  전부 평균(LOO)   4.82%p   16.13%p   26/40    0.16%p
  지금 산식        5.85%p   16.24%p   19/40    8.21%p
  실측               —        —        —       6.19%p
```

**모든 매장에 똑같은 값을 찍는 것이 산식보다 정확하다.** MAE도 ±5%p 매장 수도 그쪽이 낫다.

### ⚠️ 원인은 "평균 맞추기"가 아니다 — 정반대다

예측 퍼짐 8.21%p vs 실측 6.19%p. **산식은 자신 있게 틀린다.**

| 예측 낮은 5곳 | 예측 | 실측 | | 예측 높은 5곳 | 예측 | 실측 |
|---|---|---|---|---|---|---|
| 진주혁신도시본점 | 16.6% | 27.5% | | 청주지웰시티점 | 42.4% | 43.6% ✓ |
| 양주덕정점 | 17.0% | 29.8% | | 금촌역점 | 45.7% | 36.5% |
| 광주첨단점 | 18.7% | 30.0% | | 일산탄현점 | 46.2% | 32.9% |
| 청주대점 | 19.3% | 30.2% | | 시흥배곧점 | 48.0% | 36.0% |
| 문경시청점 | 19.4% | 30.6% | | 탕정역점 | 41.5% | 34.1% |

실측은 대부분 **27~36%에 몰려** 있는데 산식은 **16~48%로 벌린다.**
**낮게 본 5곳이 전부 실제로 30% 근처였다** — 여기부터 파는 게 값이 크다.

### 격차는 줄고 있다
```
아침  7.72%p vs 4.82%p  ->  차이 2.90%p
지금  5.85%p vs 4.82%p  ->  차이 1.03%p     (2/3 줄였다)
```

**재는 자리: `_spreadLayers.test.ts` (0)번.** 앞으로 성적을 잴 때 **항상 같이 찍어라.**

## 2. ⛔ 막힌 자리 — 경쟁점 PC 대수

**또 파기 전에 읽어라. 여섯 갈래 다 해 봤다.**

| 시도 | 결과 |
|---|---|
| 우리 매장으로 면적→대수 | R²=0.064 (전부 90~110대 규격형이라 지렛대가 없다) |
| 조사 경쟁점 138곳 | r=0.824인데 표본이 61~243대뿐 → 소형은 외삽 |
| 인허가 시설면적 | 40%가 엉터리(우리 발산역이 95대에 25㎡) |
| 인허가 총게임기수 | 70+ 는 정확한데 지역 편향 r=−0.486 · 작은 값은 **가짜**(사용자 확인) |
| 면적 문턱으로 대형만 | 빼면 오히려 성적이 나빠진다 |

**"기전이 없어서"가 아니라 "기전은 있는데 자료가 계수를 못 고른다"이다.**
소형 PC방 몇 곳을 직접 조사해 61대 아래를 메우는 게 제일 확실하다.

## 3. 어제 배운 것 — 자료원은 아는 답과 대조해서 고른다

**실체 판정 순위: 카카오 > 소상공인 상가업소 > 인허가.**
상가업소도 인허가도 폐업을 못 따라온다(사용자 확인: 구리돌다리 7곳이 *"네이버지도에 안 떠"*).
카카오는 사람이 조사한 500m 실재 273건 중 **270건(99%)**을 맞힌다.

> **나는 어제 카카오 판단을 세 번 틀렸다.** (1) "도시 편향"으로 기각 — 눈대중이었고
> 재 보니 r=−0.14로 유의선 아래 (2) 상가업소로 갈아탐 — 사용자 확인으로 뒤집힘
> (3) 40건 상한을 원인으로 지목 — 풀어 보니 성적이 안 바뀜.

**⚠️ 인허가로 목록을 만들지 마라.** 같은 건물에 등록이 대여섯 개씩 겹쳐 있어서 진짜 가게
하나가 죽은 등록을 전부 살린다(안산선부 34건 vs 실제 12건). 인허가는 **날짜만 달아 준다.**

**⚠️ 날것 상관으로 판정하지 마라.** 입지는 실측과 r=−0.193인데 잔차와는 **+0.480**이다.
날것이 음수인 건 교란이다(중심도 높은 동네는 경쟁점도 많다).
