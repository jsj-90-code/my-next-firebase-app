## 2. ⭐ 어제 제일 중요했던 것 — MAPE로 값을 고르면 안 된다

사용자가 자사 먹거리를 3.5로 낮추자고 했다가, 성적을 보고 **"MAPE 값 좋은 4로 갈까"**로
방향을 틀었다. 위쪽도 훑어보니 이렇게 나왔다:

```
  먹거리    5   MAPE 22.02%   중앙 16.4%   ±20% 58%
          4.5        22.25%        16.5%        61%
            4        22.51%        14.3%        63%   <- 지금
          3.5        22.91%        14.9%        61%
            3        23.41%        16.1%        61%
```

**MAPE는 4에서 꺾이지 않는다. 끝까지 계속 좋아진다.** 그러니 "MAPE가 4를 지지한다"는
말은 성립하지 않는다 — MAPE가 하는 말은 "자사 점수를 올릴수록 좋다" 하나뿐이고, 그건
먹거리 얘기가 아니라 **산식이 경쟁상권 매장을 전반적으로 낮게 예측한다**는 뜻이다.

게다가 MAPE만 좋아지고 **중앙값·±20% 적중은 나빠진다.** 세 자 중 둘은 4가 최선이다.

사용자 본인의 말(2026-09-18): *"일단 이러면 안 되는데 산식이 얼마 안 남았고 자료 넣을 것도
이제 끝이 보이니까 MAPE 신경 쓰게 되네."*

`textbookModel.ts` 머리말에 적힌 이 산식의 목적을 다시 읽을 것:
*"기존 산식과 다른 점은 회귀로 덮지 않는다는 것이다."* 정확도만 원했으면 만들 이유가 없다 —
운영 V62가 이미 9.26%다. **MAPE로 값을 고르면 도망쳐 나온 자리로 돌아간다.**

### 값 바꿀 때 볼 것 셋


## 3. ⭐ 다음 할 일 — 특수수요 2차 가공

사용자가 어제 마지막에 이걸 물었고 답을 못 줬다. **여기서 시작하면 된다.**

지금 값(2026-09-16 1차, `textbookModel.ts` 456줄):

```
  군부대 2.25 · 대학가 1.45 · 산업단지 1.39 · 기타 1.25 · 관광유흥 1.00 · 없음 1.00
```

수요 산식 안에서 곱한다 — `수요 = (주거 + 유동 x α) x 특수수요배수`.
V62의 특수수요와 **이름만 같고 형태가 다르다**(V62는 회귀의 이진 더미).

### ⚠️ 먼저 풀어야 할 것 — 축척이 순환한다

```
  수요 축척 A는 독점매장 3곳에서 정한다
  그런데 그중 2곳이 특수수요를 갖고 있다
     탕정역 = 산업단지/보통 · 남악 = 기타/보통 · 광주각화 = 없음
  배수를 넣으면 그 2곳 수요가 커져 A가 작아지고, "없음" 매장이 전부 밀려 올라간다
  순수 기준점은 광주각화점 하나뿐이다
```

1차 적용 결과가 이미 그 증상을 보인다:

```
  경쟁상권 수요/PC ~ 가동률 r   0.209 -> 0.297  (개선, 유의선 0.338 미달)
  필요 점유율 100% 초과         4곳 -> 5곳      (군부대 2곳은 고쳐졌으나 "없음" 3곳이 밀려 들어옴)
```

**이 순환을 안 풀면 배수를 아무리 고쳐도 뜻이 안 선다.** 2차 가공의 첫 일이 이것이다.

### 그 밖에 알아둘 것

- 표본이 유형당 **2~5곳**이다. 방향(군부대 > 대학가 ≈ 산업단지 > 없음)은 명확하지만 값은 흔들린다
- 관광·유흥은 측정값이 0.84로 오히려 낮지만 n=2라 **1.00으로 둬 뒀다**
- 강도(없음/낮음/보통/높음)는 아직 안 쓴다 — 표본 대부분이 "높음"이라 유형과 분리가 안 된다
- **특수수요가 100% 초과를 다 설명하지도 않는다.** 문경시청(197.7%)·양주덕정(124.6%)은
  유형이 "없음"이다. 문경시청은 주거1km 18,786명으로 표본 최소인데 가동률 30.6%다 —
  **인구 적은 동네를 과소평가하는 별개의 문제**다

⚠️ 2절을 먼저 읽고 시작할 것. 표본 2~5곳짜리 계수를 MAPE로 고르면 정확히 그 함정이다.
