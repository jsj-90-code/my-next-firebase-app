## 화면을 실제로 열어 확인하는 법 (어제 확립)

이 앱은 **회사 구글 SSO 로그인만** 된다(이메일/비밀번호·익명 공급자는 2026-09-10에 껐다). 그래서
에이전트가 자동 로그인할 방법이 없다. 되는 방법:

```
"/c/Program Files/Google/Chrome/Application/chrome.exe" \
  --remote-debugging-port=9222 --user-data-dir=<임시경로>/chrome-profile \
  --no-first-run --no-default-browser-check <URL> &
```

사람이 한 번 로그인한 뒤 `playwright-core`의 `chromium.connectOverCDP('http://127.0.0.1:9222')`로
붙는다. Playwright가 직접 띄운 브라우저는 구글이 로그인을 막을 수 있는데, 수동 실행 + CDP 연결은
자동화 플래그가 없어 정상 진행된다.

**함정 3가지 (어제 전부 겪었다)**

1. **캡처가 계속 타임아웃하면 앱 문제가 아니라 창이 가려진 것이다.** 크롬 창이 다른 창에 가리면
   래스터가 지연돼 `page.screenshot()`도 CDP `Page.captureScreenshot`도 멈춘다.
   `Page.bringToFront`를 먼저 부르면 40~80ms에 찍힌다. 어제 이걸로 DOM을 한참 뒤졌다.
2. **`fullPage` 캡처는 1만px짜리 화면에서 타임아웃한다.** 스크롤하며 뷰포트 단위로 찍을 것.
3. **`connectOverCDP` 세션에서는 `setViewportSize`가 안 먹는다.**
   `Emulation.setDeviceMetricsOverride`를 쓴다.

확인용 편집은 저장하지 말고 원래 값으로 되돌리거나 "변경 버리고 이동"으로 폐기한다.
