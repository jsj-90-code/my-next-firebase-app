## 코드 수정(이번 커밋)
1. **1688 보충 끔**(`cron/route.ts`, `runRound.ts`의 supplement1688 삭제): 서버가 이미 1688을 잰 시에 20~45분 뒤 다시 재서 합집합 →
   그 사이 켜진 PC만 더해져 위로만 치우침(10-10 오전 회차마다 8곳 +13~+54). 이제 한 시 = 한 시점 측정 하나.
2. **시간마다 켜진 수 ≤ 대수**(`recordRound`, `homeAgent.mjs`): 켜진 IP 목록은 원본 유지.
3. **늦게 온 회차가 lastSample(실시간 칸)을 옛 값으로 되돌리지 않음.**
4. **과응답 판정을 평가와 같은 날로**(`storeStatus`): 포트 전환 전·1% 미만 날 제외 — 희석으로 과응답 매장이 "측정 중" 통과하던 것.
5. **평균 1% 남짓(반올림 1.0)은 평가로 안 넘김**: 점포평가 `normalizePercentLike`가 1을 100%로 읽는다.
6. **중복 등록 시 "계산 제외" 문서가 정상 문서를 이기던 정렬** 수정.
7. **적용 칸 경고**(`CompetitorsTab`): 측정기 대수 ≠ 경쟁점 대수, 넣어 둔 측정기 값이 지금 측정 불가 상태.
8. **상세 화면**이 포트 전환 날을 안 빼고 100% 상한도 없어 목록과 값이 달랐던 것.
