# PC·상품 예측 비교 및 평가기간 조회

기존 가맹점의 상품 예측이 실제보다 높은지 확인할 수 있도록 검증 화면에 구성별 비교를 추가했다. 실제 상세내역은 오픈월을 제외한 다음 달부터 12개월만 조회한다.

## 변경

- 검증 요약 아래에 매장 검색이 가능한 PC·상품 비교 표: 각 예측액, 실제액, 부호 있는 오차율, 예측·실제 상품 비중.
- 예측은 기존 `runUsageCohortValidation` 결과를 그대로 사용한다. 학습표본에 속한 대상 점포는 양쪽 모형에서 제외된다. 참고용 점포를 표에 표시한다.
- 실제 구성은 동일한 기존 학습 평균으로 계산하고 검증 실제 총액과 일치하는 경우만 표시한다. 불완전한 구성이나 기간 불일치를 0으로 채우지 않는다.
- 기존 평균 규칙(평가범위 1~12개월 중 2개월차 이후 우선, 없으면 1개월차)은 변경하지 않았고 화면에 명시한다. 이번 요청은 상세 자료의 조회·표시 범위 제한이며 예측 모형 재학습 정책 변경으로 확대하지 않았다.
- 상세매출의 전체기간/연도 선택 제거. 오픈일에서 계산한 평가기간과 해당 월별 내역만 표시. 오픈일 미등록 시 전체 이력을 대신 읽지 않는다.
- 기존점 상세·목록 관리·검증·신규후보지 계산은 `listEvaluationSales`로 평가기간의 표준 문서 ID만 조회한다. 30개씩 묶고 동시 요청은 4개로 제한한다. 화면에서 단순히 숨기는 방식이 아니다.
- 백업의 전체 이력 조회와 원본 매출 저장·동기화는 유지한다. 데이터 삭제 및 보안규칙 변경은 없다.

## 검증

- 일반 테스트 23파일 466개 통과. 기간 경계, 잘못된 개업월, ID 중복, 쿼리 범위·실패 시 전체조회 방지, 비교 구성과 총액 일치 회귀 포함.
- TypeScript, 변경 ESLint, diff 검사 및 프로덕션 빌드 성공.
- 로컬 브라우저에서 운영 자료 조회 성공. 검증 표본 38곳, ±10% 52.6%, MAPE 11.5%로 기존 지표와 동일.
- 안산선부점: PC 예측 32,825,308원 / 실제 32,634,527원, 상품 예측 38,357,711원 / 실제 44,282,909원, 상품 오차 -13.4%, 예측 상품 비중 53.9% / 실제 57.6% 확인.
- 안산선부점 상세: 2023-07 오픈월은 제외하고 2023-08~2024-07의 12개월만 표시. 기존 38개월 표시에서 12개월로 감소한 것을 확인했다.

모형 비교 평균과 12개월 상세 평균은 기존 규칙상 첫 달 포함 여부가 다르므로 같다고 표시하지 않는다. 예측 비중을 특정 범위에 맞추는 보정은 하지 않았다.
