## 크론 읽기 점검 완료

`scripts/estimateCronReads.mjs`를 추가했다. 자격증명이나 네트워크 없이 기존 백업의
컬렉션 건수로 현재 크론의 문서 읽기를 계산한다.

실행: `node scripts/estimateCronReads.mjs`

- 매출 동기화: 기존점 41 + 월매출 850 = 891건.
- 프로필 동기화: 기존점 41 + 경쟁점 224 + 입지평가 50 + 설정 1 = 316건.
- 정상 실행 1회 합계: 1,207건. 기존점은 두 단계에서 각각 읽는다.
- Google Sheets 호출은 정상 경로에서 4회이며 Firestore 문서 읽기와 별개다.
- 상태 기록은 마지막에 문서 쓰기 1회다. 실제 변경분 쓰기는 시트 내용에 따라 달라진다.

이는 저장 백업과 코드로 계산한 추정치이며 운영 청구량 실측이 아니다. 재시도·인덱스 읽기·
네트워크 사용량·다른 사용자의 작업은 포함하지 않았다. 매출 단계에서 새 점포가 등록되면
프로필 단계의 읽기 건수도 늘어난다. 필터링된 검증 표본을 전체 컬렉션 대신 넣으면 과소 계산된다.
쿼리가 바뀌면 스크립트도 다시 검토해야 한다.

인계 문서의 과거 화면 사용 시나리오 14,556건에 단순 합산하면 15,763건이다.
그 시나리오는 과거 데이터로 측정됐으므로 이번 백업에 대한 정확한 일일 총량은 아니다.
무료 요금제 전환 가능 여부는 이 결과만으로 확정하지 않는다.
