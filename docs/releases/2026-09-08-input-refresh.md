# 기존점 학습 입력 연결 수정

입지와 경쟁점을 수정해도 저장된 경쟁력·수요 캐시를 학습에 사용해 예측에 반영되지 않는 문제를 수정한다. 후보지 예측과 기존점 검증은 현재 원본 자료로 파생 입력을 재계산하며, 동기화도 같은 계산을 사용한다.

- 학습용 경쟁점과 입지 자료를 필수로 받아 오래된 캐시로 우회하지 않는다.
- 후보지 자료를 전체 조회 결과에서 선택해 중복 조회를 줄인다.
- 전환 점포는 기존 계약에 따라 원본 후보지 코드로 연결한다. 시트 경쟁점도 같은 코드로 저장하며 문서 ID는 유지한다.
- 동기화에서 갱신한 기본정보를 같은 실행의 점수 계산에 반영한다.
- 과거 조사상태 필드의 호환 변환을 브라우저와 서버가 공유한다.

검증: 일반 테스트 17파일 432개, TypeScript·프로덕션 빌드·변경 파일 ESLint·diff 검사 통과. 로컬 회사 계정 로그인 후 실제 자료를 조회한 검증 화면에서 표본 38곳, ±10% 50.0%, ±20% 89.5%, MAPE 10.4%를 확인했으며 브라우저 오류 로그는 없었다.

저장 자료 재현에서는 MAPE가 10.85%에서 10.44%로 줄었지만 적중 점포 수는 같고 최대 과대예측은 27.28%에서 28.07%로 늘었다. 입력 연결 수정의 검증이며 신규점 성능 개선을 보장하지 않는다.

운영 배포와 동기화 실제 실행은 수행하지 않았다. 결과 탭의 자동 저장은 운영 자료를 바꾸므로 UI에서 실행하지 않았고 순수함수 회귀 테스트로 검증했다. 같은 실물 경쟁점을 서로 다른 문서로 중복 등록한 경우를 자동 병합하지 않는다.

2026-09-08 재개 검증: 마지막 호환 처리와 시트 연결 수정을 포함한 전체 변경을 검토하고 일반 테스트 432개, TypeScript, 변경 파일 ESLint, diff 검사를 다시 통과했다. 위 빌드·브라우저 결과는 앞선 작업에서 확인한 결과이며 이번 재개 시 다시 실행하지 않았다.
