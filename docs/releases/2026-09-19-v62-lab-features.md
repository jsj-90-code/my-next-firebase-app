## 0. 사용자 요구와 그게 왜 좋은 설계인가

> *"v62에 실험실데이터 조합 잠시 찾아보고, 적용해보자. (...) 실험실데이터 무조건 mape로
> 가는 게 아니라 실험실에서 나온 내용 중 적절한 요소가 아닌 것들, 그니까 우리가 이 내용은
> 아니다라고 정정한 것들도 함께 적용해보자."*

**기각한 항목을 같이 태우면 그게 위약군이 된다.** 이게 판정의 핵심이다:

```
  채택군만 좋아지고 기각군은 안 좋아진다  ->  진짜 신호
  기각군도 똑같이 좋아진다              ->  칸을 하나 더 준 효과일 뿐 = 과적합
```

위약군 없이 채택군만 태우면 "좋아졌다"를 **반드시** 얻는다(자유도가 하나 느니까).

### 운영 코드를 안 고치고 칸을 더한 방법

`ValidationStoreInput.competitorDistanceRatio`가 2026-09-11에 만든 **실험용 피처 슬롯**이다.
값이 있으면 `empiricalFeaturesFor`가 피처를 한 칸 더 붙이고 `buildMinCoefficients`도
하한선 0으로 같이 늘어난다. 거기에 아무 변수나 태웠다.

## 1. 기준선

```
  V62 (리브원아웃 · 정식검증군 n=38)
    MAPE 9.17% · 중앙 7.89% · ±10% 66% · ±20% 97% · 하한선에 붙은 계수 4개
```

(V62 목표 4개 중 **±10%만 미달** — 2026-09-10 진단. 그래서 ±10%를 먼저 본다.)

## 2. 실험실 변수 아홉을 하나씩 태웠다

```
                                 MAPE      중앙    ±10%   ±20%  하한선     대치
  기준선 (칸 없음)                 9.17%    7.89%    66%    97%     4
  ── 실험실 채택군 ──
  QSC 관리지수 log(q/92.6)        7.90%    6.39%    71%    92%     4    5곳   ← 유일한 개선
  상권 중심도 ν                   9.25%    7.96%    66%    97%     5    3곳
  교과서식 예측 가동률               9.53%    8.45%    66%    92%     4    3곳
  특수수요 배수 log(m)             9.61%    8.88%    61%    97%     4
  ── 실험실 **기각**군 = 위약 ──
  편심도 ω (09-18 기각)           9.31%    7.86%    63%    95%     5    3곳
  2km 대체 PC방 수 (09-19 기각)    9.25%    8.36%    63%    95%     5
  주거 2km/1km 비 (09-19 기각)    9.33%    8.34%    68%    92%     4
  log(주거 1km) (09-18 기각)      9.36%    8.03%    63%    97%     5
  유동 400m/100m 비 (안 쓰는 값)   9.62%    7.86%    66%    95%     5
```

**위약군은 아홉 중 하나도 MAPE를 못 낮췄다.** 시험이 제대로 작동한다는 뜻이다.
그리고 **채택군 넷 중에서도 QSC 하나만** 좋아진다 — 중심도·교과서식 예측·특수수요 배수는
V62를 **나쁘게** 만든다.

> ⚠️ 결측은 표본 평균으로 채웠다(표준화 후 0 = "모른다는 중립"). 대치가 많을수록 그 후보는
> **불리하게** 측정된다 — QSC는 5곳을 대치하고도 이겼다.

## 3. 순수 잡음 대조군 — 난수 칸 40회

```
              기준선    난수 5%   난수 중앙   난수 95%
  MAPE       9.17%    8.86%    9.28%    9.43%
  중앙         7.89%    7.28%    7.89%    8.60%
  ±10%         66%      58%      66%      66%
```

- **난수 중앙(9.28%)이 기준선(9.17%)보다 나쁘다.** V62는 "아무 칸이나 더 주면 좋아지는"
  과적합 상태가 **아니다.** 이 시험은 공짜 개선을 주지 않는다.
- **QSC의 7.90%는 난수 최고치(8.86%)보다도 한참 밖이다.** 40회 중 0회가 도달했다.

## 4. QSC가 무엇을 고치나 — 물리적으로 말이 된다

```
  ── 좋아진 곳 (QSC 낮음) ──          ── 나빠진 곳 (QSC 높음) ──
  구미산동점  QSC 73.9  17.9% -> 3.9%   남악점    QSC 98.5   6.0% -> 11.9%
  발산역점    QSC 83.2  15.3% -> 6.2%   김포구래점 QSC 96.4  16.0% -> 20.6%
  장산점     QSC 82.7   9.7% -> 1.1%   증평점    QSC 96.0  10.8% -> 14.7%
  진주혁신도시  QSC 87.0   7.7% -> 3.5%   광주첨단점 QSC 98.0  21.0% -> 24.8%
```

**관리 점수가 낮은 매장을 산식이 과대예측하고 있었고, QSC 칸이 그걸 정확히 끌어내린다.**
구미산동점(QSC 73.9, 표본 최저)이 −14.0%p로 제일 크게 고쳐진다. 우연한 맞춤이 아니라
"관리는 매출에 실재한다"(2026-09-17 탄력도 0.84)와 같은 얘기다.

### 대가 — ±20%가 97% → 92%

```
  ±20%를 벗어난 매장 2곳:  인천서창점 19% -> 21%  ·  김포구래점 16% -> 21%
```

평균은 좋아지는데 꼬리 두 곳이 밖으로 나간다. **세 자 중 하나가 반대로 간다.**

---

## 5. ⚠️⚠️ 그런데 후보지 예측은 한 톨도 안 바뀐다

**QSC는 개점 뒤 매장을 돌아보고 매기는 점수라 후보지에는 존재하지 않는다.**
없으면 평균(표준화 후 0)이 들어가 기여가 정확히 0이다.

즉 이 개선은 **기존점 사후 설명력**이지 **후보지 예측력**이 아니다.
실험실에서도 같은 이유로 2026-09-15·09-17 두 번 보류됐다(`docs/backlog.md` "결정 대기").
**V62에서도 결론이 같다.**

## 6. 사용자 질문에 대한 답

> *"기본산식(V62)을 현재 실험실 데이터에서 나온 내용으로 대입했을 때 적중률 향상 가능한지?"*

**후보지 적중률 기준으로는 — 지금 실험실 산출물 중 올릴 수 있는 게 없다.**

| | |
|---|---|
| 후보지에 값이 있고 V62를 개선하는 변수 | **0개** |
| 후보지에 값이 있지만 V62를 나쁘게 하는 변수 | 중심도 · 교과서식 예측 가동률 · 특수수요 배수 |
| V62를 개선하지만 후보지에 값이 없는 변수 | **QSC 하나** (기존점 MAPE 9.17→7.90%) |

실험실이 지금까지 만든 것들(입지 5항목·유효거리·교과서식 수요식·특수수요 배수·2km 상권
자료)은 **교과서식 산식 안에서는 뜻이 있지만 V62의 회귀에는 얹히지 않는다.** V62는 이미
자기 피처로 9.17%를 내고 있고, 계수 넷이 하한선에 붙어 있다 — 자료가 지금 피처도
다 지지하지 못하는 상태라 칸을 더 주면 나빠진다.

| ±10% 66% → **71%** (미달 지표가 목표에 근접) | 화면에서 "후보지엔 영향 없음"을 설명해야 함 |
