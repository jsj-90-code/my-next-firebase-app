## 2. 개점 후 경쟁점 핑봇 재측정 알림

- 검증 탭 상단 `RemeasureReminder`: 후보지에서 전환된 기존점(`originCandidateCode`)이 개점 **3개월** 이상이고 경쟁점에
  `pingbotRemeasurePeriod`가 하나도 없으면 매장·경과 개월·개점 전 기준값 보유(n/전체)를 띄운다. 6개월 넘으면 "권장 시기 지남".
  기준값 없는 매장은 "재측정 불가"로 표시(오송 같은 경우). 새 조회 없음(화면이 이미 읽은 기존점·경쟁점).
- 재측정 값 쓰기: `scripts/writePingbotUpdates.mjs --remeasure --period=… --file=…` → `pingbotRemeasureUtilization/Period`에 쓰고
  기준값(`pingbotUtilization`)은 그대로. 쓰면 알림이 사라진다.
- 타입: `Competitor.permitHint` · `pingbotRemeasureUtilization` · `pingbotRemeasurePeriod`(옵션). 컬렉션 신설 없음 → 보안규칙 변화 없음.
