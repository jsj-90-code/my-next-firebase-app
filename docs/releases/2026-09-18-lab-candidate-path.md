# 신규후보지를 실험실 산식으로 — 2026-09-18

사용자: *"나 신규후보지 평가할건데, 기존산식이랑 지금만드는산식 두개다할거거든."*

실험실 교과서식이 그동안 **기존점만** 봤다. 후보지 경로를 열었다. 운영 V62는 한 줄도 안 건드렸다.

---

## 1. 막혀 있던 건 코드 한 군데였고, 자료는 처음부터 다 있었다

인계 문서에 후보지 PC수가 `❌ 0/11`로 적혀 있었다. **자료가 없는 게 아니라 하네스가 틀린
필드를 보고 있었다.**

| | 기존점 | 후보지 |
|---|---|---|
| PC수 필드 | `pcCount` / `evaluationPcCount` | **`expectedPcCount`** |

시험 (31)이 후보지를 `c.pcCount`로 읽어 전부 "자료없음"으로 셌다. 필드명을 고치니 **12/12**다.

> **이런 건 성적으로 안 잡힌다.** 후보지는 채점 대상이 없어서 틀려도 안 붉어진다. 그래서
> `_labCandidate.test.ts`는 성적 대신 **"입력이 제대로 꽂혔는가"**를 본다.

## 2. 기존점과 갈라지는 자리 넷

| | 후보지에서 |
|---|---|
| **PC수** | `expectedPcCount` (이름만 다르고 뜻은 같다) |
| **특수수요** | 매장 문서가 아니라 **입지평가**에 있다 — 후보지코드로 이어붙인다 |
| **관리 점수** | 신규점은 QSC 점검 기록이 있을 수 없다 → **가맹점 평균 4.20점** (기존점 중 QSC 없는 곳과 같은 값) |
| **자사 시설 빈칸** | 결측이 아니라 **표준 구성**이다 → `STANDARD_OWN_FACILITY_DEFAULTS` (팀룸 미기입 9/12곳이 정상) |

**후보지에 원래 없는 둘**은 문제가 안 된다.
- **실측 가동률** — 이게 곧 예측 대상이다. 축척은 기존점 38곳에서 이미 맞춰 뒀다.
- **경쟁력격차** — 품질 모드(`shareMode="quality"`)는 이 값을 **아예 안 쓴다.** 자사·경쟁점의
  항목별 점수로 직접 겨루기 때문이다. null로 둬도 결과가 안 변한다.

## 3. 축척은 기존점에서 맞추고 후보지는 받아 쓴다

```
기존점 38곳 ──> scoreTextbook ──> fittedParams ──> computeTextbook(후보지)
             (축척 둘을 맞춤)                      (맞히지 않고 예측만)
```

⚠️ **후보지로 축척을 다시 맞추면 안 된다.** 맞출 실측값(실매출·실측가동률)이 애초에 없고,
있다고 착각해 맞추면 되돌림 경로로 새어 들어가 **예측값으로 예측값을 맞추는 순환**이 된다.
그 자리에 `textbookModel.fittedParams()`를 뒀다 — 부르는 쪽이 파라미터를 손으로 조립하면
나중에 축척이 하나 더 늘 때 한 군데씩 빠지고, 값이 그럴듯해서 티가 안 난다.

## 5. ⭐ 실험실이 V62보다 평균 33.6% 낮다 — 배선이 아니라 산식이다

| | 실험실 | V62 | 차이 |
|---|---:|---:|---:|
| 짝지어진 11곳 평균 편차 | | | **−33.6%** |
| 절대차 중앙 | | | 32.6% |
| 제일 벌어진 곳 | 영월점 1,483만 | 7,341만 | −79.8% |

**배선 사고인지 산식 차이인지부터 갈랐다.** 같은 산식·같은 축척으로 기존점과 후보지의
중간값을 나란히 놓으면 이렇다.

| | 기존점 | 후보지 | |
|---|---:|---:|---|
| PC대수 | 100.6 | 96.3 | −4% |
| 요금 | 1,363원 | 1,496원 | +10% |
| 유동 400m | 95,053 | 102,417 | +8% |
| 주거 1km | 50,003 | 56,055 | +12% |
| 수요(명/월) | 6,803 | 6,118 | −10% |
| 수요 ÷ PC | 68.5 | 63.9 | −7% |
| **점유율(독점 뺀 값)** | **0.528** | **0.518** | **−2%** |
| 자사 사양 | 3.36 | 3.97 | +18% |
| 자사 존구성 | 3.19 | 3.57 | +12% |
| 입지 배율 | 1.032 | 1.019 | −1% |
| 예측 가동률 | 0.274 | 0.223 | −19% |

**전부 같은 범위에 들어온다. 배선 사고가 아니다.** 후보지 입력이 기존점과 같은 자로 꽂혔다.

⚠️ **점유율 평균끼리 바로 견주면 안 된다** — 기존점엔 독점매장 3곳(점유율 1.0)이 섞여 평균을
끌어올린다. 독점을 빼면 0.528 vs 0.518로 사실상 같다. 후보지엔 독점이 0곳이다.

남은 편차는 둘로 설명된다.
1. **실험실은 기존점에서 이미 −11.4% 낮게 본다**(중앙 −9.6%). 후보지에서만 생긴 게 아니다.
2. 나머지는 두 산식이 **원래 다르게 보는 몫**이다. V62는 기존 가맹점 실적에 회귀로 맞추므로
   가맹점 평균 쪽으로 당겨진다. 교과서식은 동네 수요에서 우리 몫을 떼어 내므로 수요가 얇은
   곳에서 낮게 나온다(영월점 수요 819명 — 독점인데도 1,483만).

> **어느 쪽이 맞는지는 후보지에서 판정할 수 없다.** 실매출이 없다. 개점 후 실적이 쌓여
> 기존점으로 넘어가면 그때 갈린다.

3. **먹거리·인테리어** — 자사가 전부 4.00 상수라 순위에 기여를 못 한다. 어떤 문항으로 매길지
