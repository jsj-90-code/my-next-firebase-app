# 결과 탭 읽기 비용 측정(최적화 기각) + 금액 표기 통일 (2026-09-13)

사용자가 "완성도·품질·서비스를 높일 방안을 찾아 적용하라"고 위임한 뒤 첫 회차.

## 1. Firestore 읽기 비용 — 측정하고 **최적화는 기각**

"결과 탭이 매번 전체 모형을 재학습한다"는 지적을 재봤다. 도구: `.local-tools/measure-reads.mjs`.

### 결과 탭을 한 번 열면

| 건수 | 무엇 |
|---:|---|
| 41 | 기존점 전체 |
| 50 | 입지평가 전체 |
| 224 | 경쟁점 전체 |
| 480 | 월매출 12개월 구간 |
| 4 | 후보지·설정·정확도 등 |
| **799** | **합계** |

**그중 796건(99.6%)이 후보지와 무관한 공통 학습 데이터다.** 후보지를 바꿔 열어도 같은 값을
다시 읽는다. 9곳을 한 바퀴 돌면 약 7,191건.

### 그런데 최적화할 근거가 약하다

- **비용**: 9곳 한 바퀴에 **약 61원**(Blaze 읽기 10만건당 ~850원). 무시 가능하다.
- **왕복 횟수**: 문서 수는 많지만 쿼리는 적다. `listEvaluationSales`가 이미 `documentId in`으로
  필요한 것만 30개씩 묶어 4개 병렬로 읽는다(16청크 → 4라운드). 나머지는 컬렉션당 1쿼리다.
- **계산**: `evaluateCandidate` 한 번이 **5ms**다(2026-09-13 측정). 학습이 병목이 아니다.

세션 캐시를 넣으면 몇 백 ms를 아끼는 대신 **"옛 데이터로 계산"** 위험이 생긴다. 이 프로젝트는
"계산결과를 저장하지 않고 매번 재계산"이 원칙이라 그 방향과도 어긋난다.

**결론: 지금은 하지 않는다.** 다만 **실제 로딩 체감을 재본 적이 없다** — 사람이 화면을 열어
느리다고 느끼면 그때 다시 본다. 그 경우 후보지 간 이동에서만 쓰는 짧은 TTL 메모리 캐시가
첫 후보다(796건을 재사용).

## 2. 금액 표기가 한 화면에서 갈려 있었다 — 통일

결과 탭 안에서 `formatWon`(원) 25곳과 `formatManwon`(만원) 4곳이 섞여 있었다. 하필 **직접
비교되는 자리끼리** 단위가 달랐다.

```
V62 최종예상월매출   58,280,450원      <- 원
기존점 중앙값        6,378만원          <- 만원   (바로 아래 줄)
실측 정확도 범위     52,529,xxx원 ~ ... <- 원
2,000만원 기준매출   57,700,000원       <- 원
```

두 값을 견주려면 머릿속에서 자릿수를 옮겨야 했다. 만원 표기가 2026-09-13에 새로 들어오면서
생긴 불일치다(실제 평가기록이 만원을 쓰기 때문에 도입했다).

**고친 뒤:**

```
V62 최종예상월매출   약 5,800만원
                     58,280,450원      <- 작게 병기(정밀도 유지)
실측 정확도 범위     5,300만원 ~ 6,400만원
기존점 중앙값        6,378만원
2,000만원 기준매출   5,770만원 (57,700,000원 병기)
```

"예상이 선투자 기준을 살짝 넘고, 기존점 중앙값보다는 낮다"가 **한눈에 읽힌다.**

**정밀도를 버리지 않았다.** 큰 카드와 기준매출 카드는 원 단위를 `hint`로 작게 병기한다. 세부
계산값(V61 기본예측·보수/상한 밴드·요금·상품매출)은 원 단위 그대로 뒀다 — 비교 대상이 아니라
정확한 값을 확인하는 자리다.

## 확인

`npm run build` 통과 / 테스트 665 통과 / `npm run lint` 0건. 실데이터(N012 산본점)로 화면에
나올 문자열을 그대로 찍어 확인했다.

## 안 한 것

- **접근성(aria/키보드)** — 전 화면 통틀어 10건뿐이라 후보로 봤지만, 이 도구는 사내 평가자
  한 명이 쓰는 내부 화면이라 우선순위가 낮다고 판단했다. 표 `scope`·`role="alert"` 정도는
  값이 있을 수 있어 다음 회차 후보로 남긴다.
- **실제 로딩 시간** — 브라우저 없이는 못 잰다. 사람이 체감을 말해주면 1번을 다시 연다.
