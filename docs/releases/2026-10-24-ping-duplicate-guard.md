# 2026-10-24 — 측정기 중복 등록 막기 · 상권 묶음 제안 · 우리 매장 검색

이유(사용자): 점포 담당자가 여럿이고 신규 입사자도 있어, 측정기에 이미 들어간 상권·매장인지 모르고 새로 등록한다.
신규후보지뿐 아니라 조사용으로도 상권을 넣다 보니 "구로점·구로디지털점·구로디지털단지점"처럼 묶음 이름이 갈라진다.
매장명으로는 판정하지 않고 IP·주소로 본다.

## 바꾼 것
- `src/lib/pingMonitor/duplicate.ts`(새로)·시험 15개: 주소 → 건물 단위 열쇠(도로명·지번, 시·도 줄임말 통일) + 층·호수, IP 겹침, 이미 겹친 쌍 찾기, 이름 표기 정리(띄어쓰기·피시↔PC).
- 등록 칸(`StoreForm.tsx`, 측정기 등록·상세 수정·후보지 경쟁점 탭 공통)
  - **IP가 하나라도 겹치거나 주소가 같으면 저장 안 됨** — 어느 매장과 무엇이 겹치는지(새 창 링크) 보여 주고 그쪽을 고치게 안내.
    같은 건물 다른 층·호수는 알림만. 한쪽에만 층·호수가 있으면 막지 않고 "다른 층(다른 매장)이 맞습니다" 체크를 받는다(사용자 후속 요청 — 기존 등록에 층이 없으면 신규 담당자가 그 층을 몰라 막혀 버리던 빈틈). 둘 다 층이 없거나 층까지 같으면 막는다. 측정 중지한 등록과 겹치는 건 알림만(폐업 자리에 새 PC방).
    수정 화면은 고친 칸이 새로 겹칠 때만 막는다(원래 겹쳐 있던 등록을 고치러 들어와 저장할 수 있게).
  - **새 등록은 매장 위치 필수** — 주소(좌표 자동)·지도 PC방 핀·"내 위치 → 지금 위치를 이 매장 위치로" 중 하나. 옛 등록 수정에는 안 걸림.
  - **상권 묶음**: 직접 입력할 때 500m 안 묶음은 같은 상권으로 보고 "이 묶음에 넣기"를 권하며, 새 이름을 만들려면 "다른 상권이 맞습니다"를 체크해야 저장. 1km 안·이름 비슷(한쪽이 다른 쪽을 품음)은 안내만.
  - "우리 매장" 칸을 검색 칸으로(`OwnStorePicker.tsx`) — 표기 차이 무시, 위치를 알면 가까운 순·거리 표시.
- 측정기 목록: 측정 중인 등록끼리 겹치는 쌍을 "겹치는 등록 N건"으로 띄우고 매장 링크.
- `/api/ping-monitor/nearby` 주소 찾기가 지번도 돌려줌(도로명으로 적은 주소와 지번으로 저장된 기존 등록을 맞추려고).
- `listOwnStoreOptions`가 기존점·후보지 좌표를 같이 돌려줌(추가 읽기 없음).
