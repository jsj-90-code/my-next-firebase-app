# 점포평가 품질 개선

Claude 인계 기준 커밋: `d1c8903`. 별도 작업 폴더에서 진행했다.

## 변경

- 검증 결과 검색·대상 필터·매장 상세 연결 추가. 필터는 전체 적중률 집계에 영향을 주지 않는다.
- 공식 검증 제외 점포와 제외 사유 표시. 표본 0건을 성능 미달이나 0% 정확도로 오해하지 않도록 주요 요약을 정리했다.
- 리브원아웃 검증의 보장성 표현과 현재 후보지 계산 방식에 관한 잘못된 설명 수정.
- 오차 구간 집계에서 정확히 0%인 점포가 빠지던 경계값 오류 수정. 예측값 계산은 바뀌지 않는다.
- 후보지 복사 시 원본 담당자의 판단 금액·근거·작성자·작성 시각을 초기화한다. 새 후보지를 원본의 판단과 혼동하지 않도록 했다.
- 후보지 목록·대시보드·검증 화면에 조회 재시도 제공. 목록 조회 실패와 실제 빈 목록을 구분한다.
- 후보지 복사·삭제 처리 중 다른 행의 동일 작업을 비활성화한다.
- 모바일 메뉴 가로 스크롤, 현재 메뉴 표시, 본문 바로가기, 키보드 초점 표시, 검색 접근성 보완.
- 점포평가 화면 오류 복구 경계 추가.

## 유지한 사항

예측 가중치·회귀 계수·학습 기준·담당자 판단의 산식 분리 규칙은 변경하지 않았다. 운영 데이터와 Firebase 설정도 직접 변경하지 않았다. 기존 크림색·테라코타 디자인 토큰을 유지했다.

## 검증

- 전체 Vitest: 675개 통과, 기존 22개 건너뜀. `_*.test.ts` 탐색용 파일 제외.
- 신규 회귀 검사 4개: 복사 시 판단 분리/원본 없음, 오차 구간 0%/경계/미측정 처리.
- Claude의 로컬 검증 스냅샷을 사용한 저장값 정합성 검사 포함. 테스트를 위해 운영 DB에 쓰지 않았다.
- ESLint 및 Next.js 프로덕션 빌드 통과.
- 브라우저 도구에 연결된 브라우저가 없어 실제 화면·클릭·모바일 배치는 미검증이다. Claude가 이전 버전을 확인한 결과를 이번 변경의 화면 검증으로 간주하지 않는다.

## 후속 확인

브라우저 연결 후 밝은/어두운 테마, 390px/1280px 화면에서 메뉴·본문 바로가기·검색 필터·조회 재시도를 확인한다. 복사 동작의 실제 DB 쓰기 검증은 테스트용 후보지를 이용해야 한다. 정확도 개선은 새로운 독립 표본을 확보한 뒤 평가하며, 기존 표본에 맞춘 가중치 조정은 하지 않는다.
