# 최종결과 탭 화면 사람 확인 (backlog ①)

2026-09-13 밤. `docs/backlog.md` "1) 사람만 할 수 있는 확인" ① 항목 — 최종결과 탭의 요인별 기여도
막대·결재 전 체크리스트·금액 비교가 실제로 한눈에 읽히는지 — 를 확인했다. 그동안 브라우저를 못 열어
아무도 못 봤던 항목이다. 1280px 데스크톱 폭에서 화면 전체를 이미지로 훑었다.

## 잘 되는 것 — 손대지 않았다

- **결재 전 확인할 것 (3건)**: 주의/정보 배지와 한 줄 설명이 또렷하다. 산본점의 3건(실측 가동률 없음,
  경쟁점 9곳, 7층)이 모두 실제 근거가 있는 신호다.
- **금액 비교**: "기존 가맹점과 견줘보면 38곳 중 25번째", "PC 1대당으로 보면 58.3만원(38곳 중 23번째)"이
  예측값과 나란히 읽힌다. 정확도 범위(5,300만~6,400만원)도 같은 카드 안에 있다.
- **분석 카드 이미지**: 등급 배지·예상 월매출·예측에 들어간 값이 한 장에 정리된다.
- **선투자 프로모션 판정**, **상권/경쟁 지표**: 4열 카드 배치로 값이 흩어지지 않는다.

## 고친 것 2가지

### 1. 기여도 막대의 0축이 사실상 보이지 않았다

좌우로 뻗는 막대의 기준선이 `1px 폭 × 6px 높이 × 투명도 20%`라, 화면에서는 축이 없는 것처럼 보였다.
"올린 요인과 내린 요인이 한눈에 갈린다"는 원래 의도가 살지 않고, 결국 오른쪽 퍼센트 숫자를 읽어야
방향을 알 수 있었다. 축을 막대(6px)보다 길게(12px) 빼고 투명도를 30%로 올렸다.

값 자체와 정렬·색은 그대로다. 계산은 손대지 않았다.

### 2. 가장 쓸모 있는 기능이 가장 안 보이는 자리에 있었다

같은 화면의 `<details>` 4개 중 "요금 변경 영향 계산"과 "적용된 산식과 계수 보기"는 카드 박스
(`app-card rounded-xl p-4`)인데, **"왜 이 매출인가 — 요인별 영향 보기"만 테두리 없는 작은 회색
글씨**였다. 접힌 상태에서는 눌러볼 수 있다는 티가 안 난다. 바로 아래 "요금 변경 영향 계산"과 같은
카드 스타일·같은 글자 크기로 맞췄다.

## 관찰만 하고 안 고친 것

- `+`/`−` 색(초록/올리브)이 서로 아주 뚜렷하진 않다. 다만 퍼센트에 부호가 같이 붙어 있어 색에만
  의존하지 않으므로(WCAG 1.4.1 충족) 색은 건드리지 않았다.
- "세부 계산값 보기"도 테두리 없는 글씨다. 부차적 정보라 그대로 뒀다.

## 후속 마감 (같은 날 밤, 화면 재확인 후)

위 1차 수정 뒤 배포본을 다시 확대해서 봤더니 **0축이 여전히 약했다.** 행마다 끊긴 12px 눈금은
확대해야 겨우 보이는 수준이라 축으로 읽히지 않았다. 눈금을 없애고 **막대 그룹 전체를 관통하는 한 줄**
(`absolute inset-y-0 left-1/2`)로 바꿨다. 이제 왼쪽이 깎는 요인, 오른쪽이 올리는 요인인 게 한눈에
갈린다.

같이 고친 것 — **경쟁점 목록의 `수정`·`삭제` 버튼**. 앞선 모바일 확인에서 26px로 작다고 관찰만 하고
넘겼는데, `삭제`가 `수정` 바로 옆 8px 간격에 있어 모바일에서 잘못 누르기 쉬운 배치였다. 크기를
44×26 → **48×34**, 간격을 8 → **12px**로 키웠다. 배포본에서 실측 확인했다.

교훈: DOM 측정("넘침 0")만으로는 이런 게 안 잡힌다. 실제 이미지로 봐야 하고, **1차 수정 후에도 다시
봐야 한다** — 이 0축은 고친 뒤에도 부족했다.
