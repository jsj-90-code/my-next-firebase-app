# 주말 적중률 개선안의 웹 적용

## 변경

접근가시성(1~5점)을 여섯 번째 학습 특징으로 추가한다. 기존점 실제 매출을
`1 + 외부유입 보정률`로 나누어 차감 전 목표를 학습하고, 예측 대상 점포의 보정률은
최종 V62에서 적용한다. 실제 매출과 입지·경쟁점 원본은 변경하지 않는다.

운영 설정 `v61Training.modelVariant = visibility-inflow`로 활성화한다.
고정 검증 조합은 lambda 10, 회귀/중앙값 비중 1/0, 가시성 계수 하한 0.05다.
나머지 계수 하한과 가동률 상한은 기존 설정을 사용한다. 기본값은 기존 모형으로 유지해
코드 배포와 운영 설정 전환을 구분하고, 기존 문서와 이전 설정의 호환성을 유지한다.

후보지 결과, 정식/외부 검증, LOOCV 진단에서 같은 특징과 학습 목표를 사용한다.
후보지코드가 변경된 기존점은 originCandidateCode로 입지평가를 연결한다.
학습 표본은 완료월 기준을 충족하고 가시성이 평가된 점포만 사용한다.
가시성 미입력 후보지는 검증 전 임시 근사치로 표시하며, 미평가 기존점은 정확도에 포함하지 않는다.
화면의 계수 표와 모형 설명도 여섯 특징 및 차감 전 학습 목표를 표시한다.
