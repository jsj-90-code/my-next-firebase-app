- 기준: 운영 브랜치 `327207b`, 주말 브랜치 `4339134`.
- 반영: 후보지/기존점 전환 시 편집 상태 초기화, 이전 조회 응답 무효화,
  조회 실패 시 로딩 종료와 오류 표시, 저장 후 재조회 상태 관리,

  테마 상태 동기화, 카카오/엑셀 자료 처리의 TypeScript 타입 정리.

  A4 모델 변경은 과소예측 검증 미통과로 반영하지 않는다.
  관련 분석 파일 및 작업 보드는 `weekend-work`에 보존한다.
- 배포용 코드 검증: Next.js 프로덕션 빌드와 TypeScript 통과,
  일반 테스트 14개 파일 417개 통과, `eslint src` 오류·경고 없음.
- 배포 절차: 운영 환경으로 도메인 전환 없이 빌드한 뒤 응답을 확인하고,
  정상 결과가 확인되면 운영 도메인에 연결한다. 배포 후 로그인된 브라우저에서
  목록·상세·설정·좌석 화면을 확인한다.
- 실제 업무 레코드의 저장/삭제를 사용하는 파괴적 검증은 수행하지 않는다.
