# 기존 가맹점 상세매출

기존 가맹점의 월매출 기록에 합계만 표시되던 문제를 해결했다. 가맹점 상세 화면에 `상세매출` 탭을 추가하고 목록에 바로가기를 제공한다. 목록의 관리 패널도 같은 표시 컴포넌트를 쓴다.

- 월별 PC매출, 상품매출, 총매출, 총매출 중 상품 비중을 표시한다.
- 연도별 조회와 선택 기간의 월평균 PC·상품·총매출, 합산 금액 기준 상품 비중을 제공한다.
- 요약은 두 금액이 모두 있는 지난 월만 포함한다. 누락·음수·비유한 금액은 0원으로 바꾸지 않는다. 총매출이 0이면 비중은 표시하지 않는다.
- 현재월·미래월은 내역에서 미완료로 표시하고 요약에서 제외한다. 평가용 오픈 초기 평균과 조회 기간이 다를 수 있음을 설명한다.
- 신규후보지 최종결과에도 상품 비중을 표시한다. 예측 산식·계수는 변경하지 않았다.
- 기존 인증과 `listExistingStoreSales(storeCode)` 조회를 재사용한다. 동기화·DB 구조·보안규칙 변경 및 운영 데이터 쓰기는 없다.

## 원본 확인

2026-09-09 Google Sheets 커넥터로 매출DB 메타데이터, A1:QD3 헤더, A3:B885 지점 색상, A330:QD377 금액을 조회했다. 지점명 노란색이라는 기존 블랙라벨 판정 기준을 적용했다.

2026년 8월 PC·상품 금액이 모두 있는 블랙라벨은 39곳이다. 각 점포의 `상품/(PC+상품)`을 단순평균하면 52.185%, 최소 40.405%, 최대 62.081%로 사용자가 제시한 평균 52%, 범위 40~62%와 일치한다. 모든 기간에 적용할 고정 비율로 해석하지 않는다.

과거 헤더에 `PC대비 상품비율`, 최근 헤더에 `매출대비 상품비율`이 혼재한다. 일부 저장 비율은 금액 역산과도 차이가 있어 화면에서는 PC·상품 금액으로 분모를 통일해 계산한다. 시트 수식은 수정하지 않았다.

브라우저에 이미 열려 있던 호구포역점 운영 결과는 PC 42,639,407원, 상품 45,662,602원으로 상품 비중 51.7%다. 별도 보관된 9월 8일 검증 결과 38곳의 예측 상품 비중은 평균 52.4%, 범위 46.7~61.3%다. 두 비교 모두 구성 예측의 정확성이나 모든 신규점의 적정성을 입증하는 것은 아니며, 상품이 PC보다 높다는 이유로 모형 비율을 제한하지 않았다.

## 검증

- 일반 테스트 20파일 458개 통과(금액 누락·0원, 저장비율 무시, 미완료월 제외, 기간 가중 비중 회귀 포함).
- 변경 파일 ESLint 통과. 최초 UI 변경 프로덕션 빌드 성공.
- 로컬 브라우저에서 운영 자료 조회 성공. 안산선부점 2026년 8월 PC 28,754,000원, 상품 45,772,200원, 총매출 74,526,200원, 비중 61.4%가 원본과 일치한다.
- 2026년 필터에서 8개월로 변경되고 월평균 PC 26,976,750원, 상품 42,129,788원, 총매출 69,106,538원, 기간 비중 61.0%가 표시되는 것을 화면으로 확인했다.
