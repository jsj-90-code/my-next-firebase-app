# 입력 보호 브라우저 확인

2026-09-13 저녁. 로컬 프로덕션 빌드(`localhost:3100`)를 연결된 Edge에서 확인했다.

## 확인 결과

- 기본정보: 후보지명을 미저장 상태로 바꾼 뒤 경쟁점 탭 이동 시 경고 표시. 계속 입력하기를 선택하면 입력 유지. 변경 버리고 이동을 선택하면 경쟁점 화면으로 이동.
- 기본정보: 브라우저 뒤로가기 시 경고 표시, 취소 후 입력 유지.
- 경쟁점: 기존 경쟁점 편집 중 이름을 변경한 뒤 입지평가 이동 시 경고 표시. 취소 후 입력 유지, 폐기 후 입지평가 이동.
- 입지평가: 지도판단메모 변경 후 목록 링크 이동 시 경고 표시. 취소 후 메모 유지. 브라우저 뒤로가기 경고에서 폐기를 선택하면 후보지 목록으로 이동.
- 테스트 입력은 저장하지 않고 폐기했다. 후보지 목록의 기존 이름 유지 확인.
- 390px 뷰포트에서 기본정보 및 경쟁점 편집 입력·선택·버튼의 가로 넘침 0개. 320px에서 입지평가 입력 요소 가로 넘침 0개, 목록 문서 가로 넘침 없음. 임시 뷰포트 설정은 복원했다.
- 수집된 브라우저 오류 로그 없음.

## 확인 한계

연결 브라우저는 Edge Game Bar의 standalone sidebar 모드다. 새 탭 생성은 제한되고 화면 캡처는 두 차례 시간 초과되어, 모바일 확인은 DOM 렌더링과 실제 요소 좌표·너비 측정 기준이다. 이미지로 겹침·시각적 완성도를 확인한 것으로 간주하지 않는다.

자동화 reload 호출에서는 네이티브 beforeunload 대화상자를 관찰하지 못했고, Ctrl+R은 이 모드에서 새로고침을 일으키지 않았다. 따라서 새로고침 네이티브 경고의 실제 표시·취소는 미검증이다. 코드의 beforeunload 처리와 실제로 확인한 앱 내 경고를 구분한다.
