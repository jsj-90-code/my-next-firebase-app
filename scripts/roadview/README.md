# 로드뷰 판독 하네스 (2026-09-16)

입지 4번(동선 방해)·5번(가시성)은 **자동으로 긁어올 자료원이 없다.** 유일하게 확인 가능한
경로가 로드뷰인데, 사람이 52곳을 하나씩 열어보는 건 품이 크다. 그래서 카카오 로드뷰를
자동으로 띄워 캡처하고 AI가 **예/아니오 사실만** 판정한다.

## ⚠️ 점수를 매기지 않는다

AI가 이미지를 보고 "가시성 4점" 같은 걸 매기면 **이미 폐기한 값을 다시 만드는 것**이다.
기존 `visibilityScore`(1~5)가 52곳 전부 있지만 AI 주관 점수라 안 쓰기로 했고, 주관
3항목(상권위치·동선/선점경쟁/접근가시성)도 같은 이유로 버렸다 — 29곳 중 19곳이 같은
점수라 변별이 안 됐다.

사용자 원칙(2026-09-16): **"예/아니오 사실 질문으로 물어야 한다."** 이 하네스는 그 원칙을
지킨다. 그리고 AI 판정도 검증 대상이라 **사람이 표본을 직접 보고 대조**해야 한다.

## 문항 — 전부 "예 = 나쁨"

답이 예일 때 좋은지 나쁜지가 문항마다 정해져 있어야 나중에 계수 부호를 안 헷갈린다.
(첫 초안의 "매장 앞 도로가 왕복 4차선 이상인가"는 방향이 안 정해져서 버렸다 — 큰길은
노출이라는 가산 요인이면서 단절이라는 감점 요인이라 한 문항에 두 방향이 섞였다.)

**4번 동선 방해**
1. 제일 붐비는 쪽과 우리 사이에 왕복 4차선 이상 도로·철길·하천이 있는가
2. (1이 예일 때) 그 사이에 횡단보도·지하도·육교가 없는가
3. 건물 출입구가 대로변이 아니라 이면도로·뒷골목에 있는가
4. 건물 앞에 계단·경사 등 보행 장애가 있는가

**5번 가시성**
1. 건물 정면이 주 보행로를 등지고 있는가
2. 가로수·육교·옹벽·구조물에 건물 정면이 가려지는가
3. 매장이 있는 층의 외벽이 도로에서 안 보이는가

⚠️ 간판·입간판·배너는 **뺐다**(사용자 판단). 점주가 바꿀 수 있는 건 입지가 아니다.

## 쓰는 법

```bash
# 0) playwright-core가 필요하다(저장소에 안 넣는다 — 스크래치패드에 깐다)
npm i --prefix <스크래치패드> playwright-core

# 1) 좌표·층수·붐비는 방위를 모은 targets.json을 만든다
#    .local-tools/geocoded-sites.json + kakao-directional.json + validation-snapshot.json에서 뽑는다
#    tilt는 층수에서 정한다: 지상 -(층-1)*6도(최대 -35), 지하 +10도

# 2) 키를 주입한 페이지를 만든다 (.env.local의 NEXT_PUBLIC_KAKAO_MAP_JS_KEY)
#    pair.template.html의 APPKEY를 치환해서 임시 파일로 저장

# 3) 캡처 — 지점당 한 장(매장 정면 + 붐비는 쪽 나란히)
node scripts/roadview/shotPairs.mjs <pair.html> <targets.json> <출력폴더>

# 4) 두 장씩 세로로 붙여 판독 매수를 절반으로 (가로 1600 유지)
node scripts/roadview/merge.mjs <캡처폴더> <출력폴더>
```

## 함정 (실제로 겪은 것)

- **tilt 부호가 반대다.** 카카오 로드뷰는 **양수가 아래**를 본다. 고층 매장을 보려면
  음수를 줘야 한다. 처음에 +30을 줬다가 도로만 찍혔다.
- **촬영지점이 너무 가까우면 고층이 화각 밖으로 나간다.** 문산점(6층)은 촬영지점이 14m라
  상층부를 못 봤다. 반대로 광주첨단점은 61m로 멀어서 가로수에 다 가렸다.
- **로드뷰 촬영 시점이 매장 오픈보다 앞설 수 있다.** 광주각화점은 아직 아파트 단지·공터가
  찍혀 있어 판정 자체가 불가능했다.
- **로드뷰가 아예 없는 곳이 있다.** 화명대로점은 반경 150m 안에 촬영지점이 없다.
- 캡처는 `chromium.launch({ executablePath: 크롬 경로 })`로 돈다. 경로에 역슬래시를 쓰면
  이스케이프에서 깨진다 — **슬래시로 쓴다.**

## 남은 빈틈 (문항을 손볼 때 참고)

- **단지 담장**: 창원남양점은 붐비는 쪽이 아파트 단지 담장으로 막혀 있는데, 4-1은
  도로·철길·하천만 물어서 안 잡힌다.
- **지하층과 5-3의 중복**: 지하 매장은 5-3("매장층이 도로에서 안 보이는가")이 구조적으로
  항상 예가 된다. 입지 2번 접근성(층수)이 이미 같은 사실을 쓰므로 중복 위험이 있다.
  계수를 붙이기 전에 두 항의 상관을 먼저 봐야 한다.
