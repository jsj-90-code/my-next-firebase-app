# 견적서 도구 설치 안내 (클로드가 읽고 따라 하는 순서)

사람용 매뉴얼: Claude Docs "PC가맹_견적서단가갱신도구_설치사용_매뉴얼_V01_20261023" (매뉴얼 대장 W04).
이 파일은 클로드(데스크톱 앱의 Code 화면 또는 터미널 클로드 코드)가 설치를 대신할 때 따르는 순서다. 사용자가 "설치해 줘"라고 하면 위에서부터 진행하고, 각 단계 결과를 짧게 알린다.

1. **Node.js 확인**: `node -v` — 20 이상이면 통과. 없거나 낮으면 사용자에게 알리고 `winget install OpenJS.NodeJS.LTS` (Windows)로 설치, 새 터미널에서 다시 확인.
2. **도구 설치**: 이 폴더에서 `npm install`.
3. **연결 정보**: 사용자가 준 두 줄을 이 폴더의 `.env.local`에 그대로 넣는다(없으면 새로 만든다).
   ```
   QUOTE_OAUTH_CLIENT_ID=...
   QUOTE_OAUTH_CLIENT_SECRET=...
   ```
   값을 대화에 다시 적거나 다른 곳에 저장하지 않는다.
4. **로그인**: `node scripts/quote/login.mjs` — 브라우저가 열리면 사용자가 회사 구글 계정으로 로그인·허용한다.
   "확인되지 않은 앱" 경고는 "고급 → 이동"을 누르게 안내한다(사내에서 만든 앱). "로그인 완료: (메일)"이 나오면 성공.
   로그인 정보는 이 PC의 `~/.isens-quote/token.json`에만 저장된다.
5. **확인(읽기만)**: `node scripts/quote/verify.mjs black` 과 `gold` — 시트를 바꾸지 않는다. "로그인 정보 없음 → 서비스 계정" 경고가 없고
   마지막 줄이 "전체 일치 ✓"이거나 차이 목록이 나오면 연결 성공(차이는 담당자가 반영 전일 수 있음 — 고치지 말고 알리기만).
6. 끝나면 "설치 완료. 단가를 주시면 견적서 스킬로 진행합니다"라고 알린다. 사용법은 `.claude/skills/quote/SKILL.md`.

막히면: 권한 없음(403) = 시트 편집 권한 요청, `npm` 없음 = 1단계부터, 로그인 창이 안 뜨면 출력된 주소를 크롬에 붙여 넣기.
